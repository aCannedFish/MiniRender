# 高度位移

A4.2a 完成真实位移与资产写出核心。输入可以是原网格，也可以是 [Loop 细分](GEOMETRY.md) 的结果；输出仍是共享位置、独立面角属性的不可变 `MeshData`。Qt 后台几何工具由 A4.2b 接入。

## 位移规则

本项目在物体局部坐标中计算：

$$p'=p+n\,s\,[h(u,v)-m].$$

$n$ 是由原始几何计算的面积加权平滑单位法线，跨 UV 与硬法线接缝共享。$s$ 对应 `scale`，单位为局部米，允许负值；$m$ 对应 `midlevel`，默认 0.5。高度取线性图像的 R 通道，允许负值与 HDR 数值，不做 gamma 转换或截断。建议通过 `Image::read(path, ColorEncoding::linear)` 读取高度数据，避免将高度当作 sRGB 底色解码。

高度采样固定使用 level 0、双线性过滤和 Repeat 寻址。UV 采用 OBJ 左下原点，图像采用左上原点，采样时翻转一次 Y。纹素中心位于 $(i+0.5)/W$。高度插值使用 double，与接缝检查使用同一函数；位移方向及最后存储的位置仍为 float。

每个共享位置只移动一次，采用首次遇到的面角高度。其他面角用于一致性检查，容差内也不进行高度平均。孤立位置不移动。完成后重新计算面积加权法线，丢弃输入的硬法线。`scale=0` 校验输入拓扑后返回原网格，保留原属性，不扫描高度。

位移会改变 BVH、可见轮廓和阴影遮挡。已有快照继续引用旧网格，新快照才使用新位置。它不会在着色阶段额外叠加一个只有法线变化的效果。

## 接缝检查

同一位置可能被多个面角引用。算法先采样全部面角，记录各位置的最小/最大位移距离，差值超过 `seam_tolerance` 就报告顶点编号。容差单位为局部米，默认 $10^{-6}$。

只检查端点会漏掉边内部不连续的高度。内部共享边还会对齐两侧 UV 的参数方向，再比较整条边的双线性高度。两侧相差相同整数 UV 平移时，Repeat 下的参数曲线相同，可以直接复用。

双线性纹理在一个纹素单元中为 $A+Bx+Cy+Dxy$。沿边的 UV 是参数 $t$ 的线性函数，所以高度是分段二次函数。算法合并两侧 u/v 穿越纹素中心格线的全部参数，将两侧高度差写成每段内的 $q(t)=at^2+bt+c$。每段检查端点，并检查落在区间内的导数零点 $-b/(2a)$。实现还采样中点来恢复二次系数，并归一化系数以避免大数求极值时溢出。

因此，端点和中点都接近、内部仍超过容差的接缝也会被拒绝。测试包含最大差值 0.16、两端与中点均不超过 0.15 的例子；容差 0.155 时仍能检测到不连续。

`maximum_seam_segments` 限制全部接缝检查的实际分段数，默认 100 万，可设为 2–1600 万。单个坐标方向产生的分段已超过剩余预算时会提前拒绝；合并后还检查实际总数。超预算会抛 `length_error`，不会跳过未检查的接缝。浮点计算仍有舍入误差，容差应与模型尺度相适应。

这种检查保证当前双线性高度在共享边上的一致性，不约束不同物体中重复存储的独立边，也不修复纹理图集。边界边只有一侧，不需要两侧一致性检查。

## 几何检查

输入必须通过 [半边流形检查](GEOMETRY.md)。位置移动后，法线面积向量在原面法线上的投影必须为正；法线转动达到或超过 90 度的面会被拒绝。法线重算沿用叉积平方长度大于 $10^{-20}$ 的面积门槛，并拒绝面积加权法线抵消的情况。

所有位移距离与新位置必须有限，新位置必须能存入 float。失败或取消不返回部分网格，也不修改输入。当前不检查全局自交，较大振幅仍可能让不相邻面相交。自适应采样密度和层级过渡属于 A4.5，当前应先进行适量的均匀 Loop 细分。

## 任务接口

入口为 `displace_mesh(input, height, settings, cancellation, progress)`。它同步执行，回调在调用线程触发。Qt 应在 worker 调用，不能在数值控件回调中直接运行。

阶段依次为拓扑、原法线、面角高度、接缝、位置、输出法线和完成。各阶段计数独立，长循环每 1024 个单位检查取消。长接缝按分段检查取消并报告当前边编号，拓扑校验阶段显示整体校验的开始/结束。回调前后也检查取消，支持控制器在回调中请求中止。

结果包含新网格、拓扑统计、采样面角数、检查的接缝边与分段数、最大接缝差值，以及 float 输出位置相对输入的最大实际位移。所有距离均为局部米。

## 运行示例

在仓库根目录执行：

```sh
cmake --build --preset macos-core-release
build/macos-core-release/minirender_tests '[displacement]'
build/macos-core-release/minirender_displacement_example
```

示例对 studio 中的 cube 资产执行三层 Loop，再使用 64×64 的周期高度图：

$$h(u,v)=0.5+0.35\sin(2\pi u)\sin(2\pi v),\qquad s=0.15\ \mathrm m.$$

图像按纹素中心生成，高度以 EXR 保留线性值。输出在 `outputs/a4.2a`，包含位移前后与重开场景的 EXR/PNG、高度图、独立 OBJ 和场景 JSON。渲染固定为 128×128、64 spp、seed=101，使用默认 MIS、深度 8 和 RR。示例检查重开后的最大 RGB 向量误差不超过 $10^{-5}$；OBJ 加载器会将法线归一化，结果不要求逐位一致。

位置拓扑、UV 接缝与输出文件约定见 [网格处理](GEOMETRY.md) 和 [资产导出](ASSET_EXPORT.md)。实现入口为 `include/minirender/geometry/displacement.hpp`；法线公共过程位于 `geometry/normals`，Loop 与位移共用该过程。
