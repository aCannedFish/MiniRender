# 点云界面

日期：2026-11-10。A5.2 接入点云工作页、独立预览和后台编辑链路。使用方法见 [点云工具](../POINT_CLOUD_UI.md)，核心算法见 [点云重建](../POINT_CLOUD.md)。

## 完成范围

- PLY 导入、选中网格面积采样、法线准备、自动/手动半径与重建。
- 独立预览相机、点圆片、法线颜色、抽样方向线及重建边界。
- 后台缓冲准备、参数冻结、完整法线缓存、进度限频与取消。
- 文件输入新建/更新物体，采样来源替换网格，保留编辑并形成单次历史。
- PLY/OBJ/场景保存、来源路径保护、旧离线快照和场景切换。

## 预览检查

CPU 将位置在 double 中居中缩放后打包为 24 字节实例属性。极大坐标、极小坐标、单点、法线抽样和全部边界段均有核心用例。位置和原始法线保持不变。

GPU 点圆片由六个顶点实例化，深度写入采用点中心。法线与边界使用线段管线读取深度。颜色对照包含 sRGB 附件编码，与主场景法线视图一致。

## 界面检查

文件流程导入 1200 点无方向球体，法线任务启动后把邻域从 20 改为 12，结果继续使用 20 并保留新控件值。恢复 20 后重建复用同一份法线缓存。准备后的点云抽样 GPU 探针为 90/90。

重建启动后切换为手动半径并关闭场景适配，当前任务仍使用启动时的自动半径和适配参数。生成独立物体与材质，实际法线/深度采样为 3072/3072，其中新物体 697 个。随后手动移动、旋转物体并再次重建，物体数量不增加，新的变换保留。

场景采样使用 3000 点、seed=77。任务启动后将控件改为 2000、seed=78，输出与独立的 3000/77 核心结果一致，GPU 点探针为 84/84。来源 cube 重建为 5983 面，使用全部 3000 个点，保留 12 个边界环、37 条边界边；候选检查 312080 次。输入与输出几何按实际状态分别报告。

新网格替换来源实例，其他共享 cube 的物体保留原指针。运行中位置、旋转和材质编辑保持。生成网格的 GPU 法线/深度为 2982/2982，其中目标物体 307 个。文件创建与实例替换分别检查一次撤销/重做。

候选预算失败保留当前网格。任务中撤销目标网格或删除目标物体，旧结果均为未应用，历史仍可恢复。切换场景会取消正在运行的采样并清理工作数据。

## 文件与成像

中文路径 PLY 导出后位置/法线一致，选择原输入路径导出会失败且输入字节保留。生成网格随场景保存，重开后使用相同几何和参数继续渲染。

24×24、8 spp、seed=101、深度 5 的旧离线任务与启动时的独立串行路径追踪逐像素一致；应用新网格后旧任务标为过期。保存重开后的离线图也与保存前的固定快照在 $10^{-6}$ RGB 向量误差内一致。

## 布局与响应

1200×800 和 960×700 布局检查覆盖字段边界、控件重叠及底部滚动可达性。macOS 原生按钮的控件边距曾导致相邻行矩形重叠；点云页行距调整为 12，并隐藏空提示行。实际界面图已检查。

50 万点样本用于实际取消与运行中退出。取消在法线邻域处理阶段通过按钮发出，普通模式和同步验证均在 59ms 返回，源点云保持原值。

普通模式独立探针记录 143 个事件，最大排队时延 64ms，运行中退出清理 64ms。同步验证记录 186 个事件、最大 142ms，清理 54ms，Vulkan 验证错误为 0。普通模式保留 500ms 阈值，参考计算和图像读回暂停计时。

完整 ASan/UBSan 点云流程通过，包括 50 万点取消与运行中退出；取消 60ms、退出清理 76ms，Vulkan 同步验证错误为 0。插桩核心回归 185/185 通过，配置为 `-O1`、`detect_leaks=0:abort_on_error=1` 和 `halt_on_error=1`，源码 Catch2 使用相同插桩。

独立 core Release 回归 185/185 通过。关联桌面检查包括六次相机拖拽及尺寸/停靠恢复、自适应细分、表面单/双面与镜像、内置场景覆盖导入。各流程通过，Vulkan 验证错误为 0；相机流程最大定时器间隔 85ms。自适应流程也复验了提取后的公共响应探针。

Debug/Release 编译数据库包含全部新增核心与 Qt 模块。桌面更新沿用固定安装包及后台验证流程。
