# 场景验收

日期：2026-11-03。A1.1–A1.5 已实现数据、编辑视口、阴影、HDR/FXAA 和纹理。本检查点增加线框视图，完成 A1，并修正连续复测捕获到的 macOS 呈现等待。

## 线框

相机页的“显示”新增线框。网格首次上传时，从各三角形的连续三个顶点生成六个边索引，以 LINE_LIST 绘制。边缓冲与网格共同缓存，同一网格的实例共享边索引；参数编辑或切换显示方式不重建它们。

先绘制正常表面，生成完整深度。线框 pass 读取这份深度，只把可见边写入独立的 UNORM 附件。它不修改主场景 HDR 和法线；EXR 导出保留真实线性辐射值。后处理在线框模式中读取该附件。附件在首次使用时清除并转换到可采样布局，窗口尺寸变化时重建。

线宽使用基础的 1 像素。顶点 shader 在 Vulkan clip space 中施加微小的深度偏移，使共面边线稳定通过测试。边线仍受前方表面遮挡，三角化对角线也会显示。共享边可能重复绘制，不需要 fillModeNonSolid、宽线或几何着色器等可选功能。

## 呈现修正

一次综合回归在拖拽中出现帧停滞。随后批量复测再次复现，日志显示窗口仍 active/exposed，UI timer 继续运行，当前帧 fence 持续未完成。这次失败没有计为通过。

线程采样定位到 MoltenVK 的异步提交队列在 QMetalLayer::nextDrawable 中等待。Qt 6.11.2 的 Cocoa 源码在 displayLayer 中切换事务呈现，并管理呈现回调及 drawable 的释放。项目的自有 Vulkan renderer 由 timer 提交，与 Qt RHI 的事务内协议没有协作接口。

在 QApplication 创建前设置 `QT_MTL_NO_TRANSACTION=1`，按 Qt 自带配置创建普通 CAMetalLayer；保留 `MVK_CONFIG_SYNCHRONOUS_QUEUE_SUBMITS=0`，普通帧继续轮询 fence。此后连续 10 轮完整交互测试全部通过，共 60 次拖拽，最大测试 tick 间隔 99ms，Validation 每轮均为 0 errors。

采样文件为 work/interaction-stall-sample.txt；修正后的连续日志为 outputs/a1-layer-repeat-0 到 outputs/a1-layer-repeat-9。诊断日志增加帧等待阶段，用于区分 fence、交换链 acquire 与正常提交。临时的采样等待代码已移除。

该结果来自本机 Qt/MoltenVK 组合。Windows 使用原生 Vulkan，以上两项环境配置均受 macOS 条件编译限制。

## 验证

```sh
python3 scripts/verify_gpu.py build/macos-desktop-debug/src/app/desktop/minirender_desktop.app --scene scenes/studio.json --wire-check --output outputs/a1-wire
VK_VALIDATION_VALIDATE_SYNC=1 python3 scripts/verify_gpu.py build/macos-desktop-debug/src/app/desktop/minirender_desktop.app --scene scenes/studio-two-lights.json --output outputs/a1-final-scene --timeout 60
python3 scripts/verify_gpu.py build/macos-desktop-debug/src/app/desktop/minirender_desktop.app --scene work/parameter-probe/dense.json --parameter-check --output outputs/a1-final-parameters --timeout 80
```

线框测试使用前方正方形与后方三角形。CPU 射线确认遮挡物，GPU 像素检查四处可见边和两处隐藏边，缩放后重复检查。线框前后逐像素比较 raw HDR，并检查切换没有网格上传或描述符重建。上述项目通过，包含同步校验的运行均为 0 errors。

约 20 万三角形的参数测试扩为 14 次控件操作，包含进入与退出线框，继续检查 UI 响应、GPU 缓存、后台 OBJ/场景导入和忙碌条生命周期。本机最终运行最大控件回调 0.82ms，修改后观察到两帧推进最多 82ms，网格上传与描述符重建均无增加。原有纹理、HDR/EXR、曝光、FXAA、法线/深度、多方向光阴影与 resize 回归通过，CPU CTest 为 24/24。

## 阅读顺序

1. SceneRenderer::upload_scene：边索引如何随网格缓存。
2. HdrTargets::create / begin_wire：颜色附件、已有深度与 pass 依赖。
3. SceneRenderer::render_wire：实例变换、索引绘制与显示模式。
4. wire.vert / wire.frag、post.frag：深度偏移、线色和后处理选择。
5. main.cpp：macOS 平台呈现配置与测试入口。
6. wire_smoke.cpp：从独立几何遮挡到 GPU 像素的检查。
