# 重网格

日期：2026-11-09。A4.4 接入各向同性重网格，包含长边分裂、短边折叠、价数翻边、切向平滑、原表面位置/UV 投影，以及实际质量与误差报告。实现与阅读顺序见 [重网格](../REMESHING.md)。

## 完成范围

- 局部可变邻接、版本化候选队列、保护边继承与逐轮重编号。
- 有向流形、link 条件、重复面、边界夹断、局部翻转和 UV 方向检查。
- 固定边界、UV/硬法线接缝和几何折痕；分裂共享位置保留两侧面角。
- 按保护边切分原表面，最近点查询传递位置和 UV。
- Jacobi 切向平滑与步长回退；发布前重新计算法线及验证拓扑。
- 实际操作次数、边长分布、目标区间比例、角度偏差和双向表面距离。
- Qt 参数、阶段进度、取消、独立资产、撤销/重做、OBJ 与场景保存。

## 核心检查

新增 8 个用例，覆盖粗平面的长边分裂、密集平面的短边折叠、扇形网格的价数翻边、扰动平面的分布改善、UV 与硬法线接缝、硬边 cube、闭合曲面投影、相近独立曲面、孤立位置、输入保留、预算及各阶段取消。

平面检查同时核对投影后 UV 与原 XY 参数对应。闭合曲面输出顶点到输入三角面的距离小于 $10^{-6}$ 米；保存输入及输出的 Euler 数、边界环、分量和孤立位置数量保持一致。重复运行输出位置、连接和面角属性一致。

独立工作树 Core Release 和 ASan/UBSan CPU 回归均为 151/151，通过。格式检查通过；core、desktop Debug/Release 的编译数据库均包含重网格核心、测试和示例。macOS 的 Objective-C++ 回归辅助文件也有独立编译参数。

## 曲面示例

## 响应检查

普通模式与 Vulkan 同步验证分别运行。普通模式单独统计后台 Qt 事件的排队时延和定时器间隔，截图与显式 CPU 参考计算暂停计时。窗口始终隐藏，运行时检查其未激活、视口未暴露。

离屏回归在大模型阶段曾记录 1513ms 排队时延，20ms 采样线程也出现约 250ms 的唤醒间隔。macOS 回归现通过 `NSProcessInfo` 的 activity 声明正在执行用户触发的有限任务，结束时释放。设置采用 `NSActivityUserInitiatedAllowingIdleSystemSleep`，允许系统和显示器休眠。API 说明见 [Apple 文档](https://developer.apple.com/documentation/foundation/processinfo/beginactivity(options:reason:))。

相同完整 Release 流程记录 913 个界面事件，最大排队时延 81ms，最大定时器间隔 191ms，恢复初始场景并启动退出测试耗时 62ms，退出清理 142ms。原有 500ms 响应阈值保留。

完整 ASan/UBSan 桌面流程通过，包含运行中退出，清理 159ms；使用 `-O1`、`detect_leaks=0:abort_on_error=1` 和 `halt_on_error=1`。C++ 与 Objective-C++ 均启用插桩，Catch2 使用相同配置从固定源码构建。两次 Vulkan 同步验证的错误数均为 0。

## 复验

```sh
cmake --preset macos-core-release
cmake --build --preset macos-core-release
ctest --preset macos-core-release --output-on-failure
build/macos-core-release/minirender_remesh_example
build/macos-core-release/minirender_remesh_example --stress
cmake --preset macos-desktop-release
cmake --build --preset macos-desktop-release
python3 scripts/verify_gpu.py \
  build/macos-desktop-release/src/app/desktop/minirender_desktop.app \
  --scene scenes/studio.json --geometry-check --timing-only \
  --output outputs/a4.4/release-timing --timeout 500
```

源场景和资产不修改。图像、生成网格与日志保留在 `outputs/a4.4` 和 `work`，不加入普通 Git 历史。Windows/NVIDIA 桌面验证按 B 阶段复验。
