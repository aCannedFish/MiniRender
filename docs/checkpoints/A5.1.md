# 点云核心

日期：2026-11-09。A5.1 接入 PLY、空间查询、PCA 法线、最小生成森林定向与多半径 Ball Pivoting，输出普通网格资产。A5.2 继续界面导入、点云/法线/边界预览和后台事务。算法与阅读顺序见 [点云重建](../POINT_CLOUD.md)。

## 完成范围

- PLY 1.0 的 ASCII、little-endian、big-endian，属性/元素重排及未知 list 跳过。
- 数量/文件/header/标量预算、有限数检查、取消、Unicode 路径与原子写出。
- 确定性 k-d 树、PCA 特征分解、邻域森林定向与精确重复点索引映射。
- 空球种子、旋转接触、进入/离开事件、共圆零角度、前沿 join/glue。
- 多半径重新激活、边与面扇检查、独立面扇输出、完整半边校验。
- 使用点/孔洞/分量/额外顶点/逐轮统计、工作预算与各阶段取消。
- 面积采样、命令行示例、OBJ/场景保存重开及实际 CPU 图像。

## 核心检查

新增 19 个用例，覆盖独立手写的二进制字节、三种编码往返、属性顺序、face/range_grid 记录、错误/截断/list 预算和取消保护。k-d 树与暴力距离排序逐项一致，特征分解检查残差与正交性。法线使用解析平面、球和分离分量作对照。

重建测试包含共圆规则平面、球、带孔平面、环面、非均匀密度、多分量和未完成面扇。球面每个输出三角形还通过全输入点的独立距离遍历检查空球条件。所有成功输出通过 `MeshData` 与 `HalfedgeMesh` 验证。

| 输入 | 验证结果 |
| --- | --- |
| 81 点规则平面 | 128 面，单边界环，Euler=1，全部点使用 |
| 700 点球 | 1396 面，无边界，Euler=2，面朝外，重复运行连接一致 |
| 带缺口的平面 | 两个边界环，Euler=0，共享边长度不跨过缺口 |
| 800 点环面 | 1600 面，无边界，Euler=0，无额外顶点 |
| 两个球及离群点 | 两个分量，无边界，保留未使用点统计 |
| 仅在一点接触的两个开放面扇 | 输出一个额外顶点，两份独立流形面片 |
| 密度变化的平面 | 大半径重新激活前沿，新增面数增加，全部点使用 |

PCA 输出继续经过 BPA、Loop、QEM 和各向同性重网格，保持闭合球的 Euler 数和边界状态。预算失败与验证、去重、索引、种子、前沿、输出等阶段取消均保留输入。

Core Release 与完整 ASan/UBSan 回归均为 183/183，通过。插桩使用 `-O1`、`detect_leaks=0:abort_on_error=1` 和 `halt_on_error=1`，Catch2 从相同插桩配置的源码构建。新增源文件已进入 core/desktop 的 Debug/Release 编译数据库。

## 环面示例

自建 64×32 环面提供 4096 面参照，面积采样 5000 点后去掉法线和连接。以 20 点邻域估计法线，最近邻间距中位数为 0.0248238 米、P90 为 0.0449819 米。建议半径采用 P90 的 2、3、4 倍。

| 半径 | 新增面 | 剩余边界边 | 重新激活 |
| --- | --- | --- | --- |
| 0.0899639m | 9996 | 8 | 0 |
| 0.134946m | 4 | 0 | 7 |
| 0.179928m | 0 | 0 | 0 |

最终 10000 面、5000 位置，单分量、Euler=0，无未使用点和额外顶点。候选检查 478291 次。全部输入点位于输出三角形上；相对独立参照网格的双向表面采样 RMS 为 0.00145342 米、最大距离为 0.0115024 米。

128×128、32 spp、seed=101 的实际 CPU 图像已检查。场景与资产保存重开后，最大 RGB 向量差为 $3.1348\times10^{-7}$。

## 扫描示例

数据来自 [Stanford University Computer Graphics Laboratory](https://graphics.stanford.edu/data/3Dscanrep/)。本次使用官方 Bunny 归档中的原始 `bun000.ply` 单次扫描，包含 40256 个位置和 204800 条 range_grid 记录。解析器按文件头读完 range_grid，将位置交给重建算法。

20 点 PCA 产生 3 个定向分量。最近邻间距中位数为 0.000516032 米、P90 为 0.000758298 米。

| 半径 | 新增面 | 剩余边界边 | 重新激活 |
| --- | --- | --- | --- |
| 0.0015166m | 77256 | 1104 | 0 |
| 0.00227489m | 312 | 854 | 882 |
| 0.00303319m | 128 | 762 | 571 |

最终生成 77696 面、39220 个输出位置。实际使用 39198 个唯一输入点，1058 点未使用，22 个位置因独立面扇生成副本。输出为 5 个面分量、19 个边界环。输入点到重建表面的 RMS 为 0.0000704722 米、最大距离为 0.0067608 米。候选检查 9220970 次。

输出保留了扫描边界，场景以实际重建网格保存并渲染。图像已检查，保存重开后的最大 RGB 向量差为 $5.96046\times10^{-8}$。

另一组演示使用 `bun_zipper.ply` 的 35947 个已有模型顶点，生成 71192 面，2 个面分量、19 个边界环。输入点到输出网格 RMS 为 0.0000564247 米，最大距离为 0.00148311 米。该记录与原始扫描分开统计。

归档 SHA-256、数据路径与命令见 [点云重建](../POINT_CLOUD.md)。原始扫描文件未加入仓库，源码仅包含自建解析模型和测试。示例输出检查输入路径，文件 SHA 在验收后再次与归档内容核对。
