# 几何界面

日期：2026-11-04。A4.2b 本机通过，接入后台几何工具、文件任务、撤销和实时/离线更新。A4.3 简化、A4.4 重网格和 A4.5 自适应继续按计划实现。

## 完成范围

- “几何”页的 Loop、线性高度、幅度/中值/接缝参数、面数与内存估计。
- 固定任务输入、实际阶段计数、取消、失败和来源变化后的结果处理。
- 按选中物体创建独立生成资产，保留共享原资产及计算期间的参数编辑。
- 单次事务、撤销/重做、旧离线快照保留和新任务使用新几何。
- 后台 OBJ 导出与场景保存，保存期间修改提示和输入资产写入保护。
- 后台准备顶点、线框索引和局部边界，界面线程上传准备好的缓冲数据。
- 普通 OBJ/场景导入复用后台校验结果及缓冲准备，减少界面重复工作。

## 数值检查

GPU 对照采用相机生成的像素中心射线，查询 CPU BVH 的世界法线和相机深度。避开三角形边缘后，RGB8 比较允许 3 个量化级误差。

| 场景 | 法线与深度匹配 |
| --- | --- |
| 初始共享 cube | 2707/2707 |
| 三层 Loop 与高度位移 | 2649/2649 |
| 撤销 | 2707/2707，调试图像恢复初始结果 |
| 重做 | 2649/2649，调试图像恢复生成结果 |
| 八层 Loop，786432 个三角形 | 2647/2647 |

高度导入保留底色和环境设置。生成后蓝色物体使用新资产，金属物体继续引用原 cube。GPU 地面阴影与 CPU 方向光遮挡查询一致：82/82 个稳定遮挡点、3335/3335 个稳定照明点匹配。直接受光曲面的 205/205 个采样点通过检查；PCF 使用接收面平面深度修正，消除了位移曲面的细碎自阴影条纹。

旧、新几何的 Qt 离线任务分别与独立 CPU 路径追踪逐像素一致。设置为 16×12、8 spp、seed=101、深度 3、关闭 RR。旧任务在几何应用后标为过期，重新开始后使用新网格。

## 交互检查

实际 Qt 控件回归覆盖高度导入、生成、参数编辑保留、撤销/重做、中文路径导出、场景保存/重开、保存期间继续编辑、原输入保护、运行中取消、目标删除和切换场景。大网格导出后重新导入，位置与面数保持一致。关闭窗口时仍有几何 worker 运行，退出过程取消并收回该线程。

表单检查覆盖水平边界、行间遮挡和底部控件的滚动访问；窗口截图已检查。参数修改更新估计，点击生成才启动计算。

## 响应时间

计时使用普通运行模式，完整 Vulkan 同步验证单独运行。独立线程先分配探针事件，再记录投递时间，统计界面实际处理事件的排队时延。计时排除截图和 CPU 参考计算的耗时，定时器间隔另行记录。

压力场景为八层 Loop，393218 个位置、786432 个三角形，并导出后重新导入同等规模的 OBJ。

| 指标 | Debug | Release |
| --- | --- | --- |
| 有效界面事件样本 | 2053 | 586 |
| 最大事件排队时延 | 42ms | 58ms |
| 生成后界面线程场景更新 | 14.8909ms | 19.195ms |
| 重新导入后界面线程场景更新 | 14.5455ms | 13.1325ms |
| 运行中退出的资源清理 | 122ms | 57ms |

修复前，主线程展开顶点与生成线框索引合计约 600–900ms，场景更新曾达到约 1.9s。上述数据准备已移入 worker，结果按不可变数据共享。界面缓存保留当前场景和最近两份未使用数据，支持历史切换。

## 复验

```sh
cmake --build --preset macos-desktop-release
ctest --preset macos-desktop-release
python3 scripts/verify_gpu.py \
  build/macos-desktop-release/src/app/desktop/minirender_desktop.app \
  --scene scenes/studio.json --geometry-check --timing-only \
  --output outputs/a4.2b/release-timing --timeout 220
python3 scripts/verify_gpu.py \
  build/macos-desktop-debug/src/app/desktop/minirender_desktop.app \
  --scene scenes/studio.json --geometry-check --sync-validation \
  --output outputs/a4.2b/debug-sync --timeout 240
```
