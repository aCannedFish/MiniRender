# SSS 核心

日期：2026-11-12。A7.5 接入均匀材质的 dipole 扩散、表面位置采样、边界 Fresnel、CPU 路径追踪和场景文件。公式与阅读顺序见[次表面散射](../SUBSURFACE.md)，界面在 A7.6 接入。

## 完成范围

- RGB 吸收、约化散射、密度和折射率，double 参数文件读写及不可变快照。
- dipole 径向核、解析面积累计、稳定 CDF 反演和精确 Fresnel 半球矩。
- 三轴、RGB 通道和多命中混合采样，逐轴计算表面积 PDF。
- 闭合、连通、朝外绕序检查，实例隔离、世界尺度、旋转和镜像变换。
- 表面反射与跨位置扩散分支、直接光、方向延续、MIS 和外部介质阴影。
- 后台任务、采样统计、暂停恢复、取消、文件与展示例程。

## 核心检查

CPU-only Release 283/283 项通过，ASan/UBSan 283/283 项通过。新增 17 个 SSS 用例，保留原有 PT、体积、SPPM、材质、几何和后台任务回归。

边界半球矩与密集独立积分对照，dipole 核与 fluence 的数值法向导数对照。整个正半轴上的面积积分恢复解析反射率，包含零吸收情形。部分面积积分检查径向采样直方图，密度缩放同时保持距离、面积密度和能量约定。

带凹槽的闭合网格经过旋转、非均匀缩放和镜像后，逐点 PDF 与原始三角面的暴力求交结果一致。测试实际出现不同投影轴命中数量不相等的样本。完整面积估计与独立世界三角面积积分相符。

共享材质的两个物体保持实例隔离。探针包含单面显示材质的前后边界。开放、断开的网格及朝内绕序被拒绝；取消标记会中止准备和采样。

## 独立能量

方向光照射立方体左面，相机观察正面中心。正面没有直接入射，辐射由跨位置扩散产生。三个采样模式各使用三个种子、每种子 10000 次路径：

| RGB | 独立面积积分 | 路径均值 |
| --- | --- | --- |
| R | 0.0422263 | 0.0408415 |
| G | 0.0408296 | 0.0391060 |
| B | 0.0253832 | 0.0242325 |

红通道标准误差为 0.00136913，三个模式使用相同的方向光估计，均值相同。外部吸收介质恢复对应的 Beer–Lambert 衰减，加入遮挡物后结果为零。

连续白色环境的方向积分与表面积积分独立计算，红通道期望为 0.219215：

| 模式 | 路径均值 | 标准误差 |
| --- | --- | --- |
| BSDF | 0.219534 | 0.00183413 |
| Light | 0.219427 | 0.00325800 |
| MIS | 0.219867 | 0.00190414 |

4cm 大理石球网格使用测量系数，独立七点五次三角形求积解析毫米尺度的峰值。红通道期望为 0.762053，路径均值为 0.765726，标准误差为 0.00507865。该检查验证实际曲面、较小扩散距离、界面反射及连续环境 MIS。
