## 验证范围

CPU Debug、Release、desktop Debug、desktop Release 和 ASan/UBSan 均为 77/77。新增测试检查参数单位/范围、采样核方向、半径和可复现性。

最终版本的 Debug、Release 各连续运行 3 轮 SSAO 窗口检查，均通过 Core Validation 和 Synchronization Validation，无 Vulkan 错误。检查包括滤波、逐像素线性合成、背景、光照隔离、调试/线框、资源复用、相机旋转、缩放及启用 AO 时的程序内 Qt 拖拽。标准场景、纹理、线框、离线任务、交互和大网格参数回归继续通过。

Qt/Cocoa 的窗口更新不能只用资源代数判断完成。测试现等待目标像素尺寸稳定后采集基准，并核对相机和图像尺寸。AO 和滤波均检查法线 alpha 的几何有效性，避免无效法线参与计算。背景断言保持精确白色检查。

验证输出位于 `outputs/a3.1/final-debug-0`、`final-release-0`，其余轮次及旧功能回归位于同级目录。截图、原始 HDR、合成 HDR 与运行日志均保留在本机输出目录，未纳入源码仓库。

## 复验

```sh
cmake --build --preset macos-desktop-debug
ctest --preset macos-desktop-debug
python3 scripts/verify_gpu.py build/macos-desktop-debug/src/app/desktop/minirender_desktop.app --scene scenes/studio.json --ssao-check --sync-validation --output outputs/ssao --timeout 65
```

实现、近似边界、原始论文和阅读顺序见 [SSAO](../SSAO.md)。本检查点的 GPU 证据来自 macOS；Windows 桌面与 NVIDIA 运行时按 B 阶段验证。
