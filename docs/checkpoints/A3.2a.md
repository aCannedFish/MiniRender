# IBL 核心

日期：2026-11-03。完成环境预处理与 BRDF 表；A3.2b 的 Qt/Vulkan 接入仍待完成，A3 保持进行中。

## 完成范围

- 与路径光照一致的 latlong 方向、旋转、接缝和极点约定。
- 非负辐射处理、源图尺寸限制及可取消的 mip 构建。
- Lambert 漫反射卷积、固定角度分辨率的 GGX 粗糙度层。
- 按 PDF/纹素立体角选择源 mip 的过滤采样。
- 与现有 GGX/Smith/Schlick BSDF 一致的 A/B 查找表。
- 实际阶段进度、协作取消、不可变结果与固定种子。

## 工程检查

CPU Debug、Release、desktop Debug、ASan/UBSan 均为 86/86。9 项 IBL 测试还覆盖参数预算、空输入、边界插值、各阶段取消、旧结果保留和固定种子。纹理桌面回归通过，Vulkan validation 为 0；新增取消参数未改变普通纹理的 CPU/GPU 过滤结果。

核心不依赖 Qt、Vulkan 或 CUDA。当前所有 bake 函数同步执行，进度回调在调用线程触发。A3.2b 将在后台调用这些函数，并接入缓存与 UI，不能把本检查点当成实时 IBL 已完成。

## 默认参考

程序化源图为 512×256，方向按源纹素中心采样。令 $s=\operatorname{normalize}(1,0.7,0.2)$，环境为

$$L(d)=\operatorname{mix}((0.3,0.2,0.1),(0.2,0.5,1.2),\max(d_y,0))
+(50,40,25)\exp\left[-\frac{\operatorname{acos}(d\cdot s)^2}{2(0.04)^2}\right].$$

默认种子 101；漫反射 32×16/256 样本，镜面 6×128×64/256 样本，BRDF 64×64/512 样本。一次 Apple M3 单线程 Release 测量为环境预处理 2243.85ms、BRDF 表 244.298ms，不含文件写出。

参考数据在 `outputs/a3.2a/reference`，包含源图、漫反射、6 层镜面环境和 BRDF 表的 EXR/PNG，以及参数记录。照明 PNG 使用 Reinhard/sRGB，BRDF PNG 仅编码 A/B 数据，不使用 Reinhard。极点端点布局见 [IBL](../IBL.md)。
