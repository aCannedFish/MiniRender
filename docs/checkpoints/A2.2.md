# 采样验收

日期：2026-11-03。实现 A2 的随机采样、基础 BSDF、面积光和环境采样，供 A2.3 路径积分使用。

## 完成范围

- PCG32、53 位 $[0,1)$ 随机数、按像素/样本派生的可复现随机流。
- 圆盘、球面、均匀/余弦半球、三角形及离散 CDF。
- 右手局部坐标系，Lambert、GGX 导体、理想镜面、理想玻璃。
- `evaluate/sample/pdf`、连续/离散测度、吞吐乘子、Radiance/Importance 模式。
- 变换后的发光三角形、方向光、常量/贴图环境光及加权光源选择。
- Latlong 坐标、旋转、极点处理、有限大小的 CDF 和完整支持集。
- 可选环境图 JSON 字段、校验、快照与保存重开；实时预览能力提示。

## 验证

CPU Debug、Release、desktop Debug 及 ASan/UBSan 均为 52/52 通过。固定种子和统计预算保存在测试中。

```sh
cmake --build --preset macos-core-debug
ctest --preset macos-core-debug
cmake --build --preset macos-core-release
ctest --preset macos-core-release
```

新增测试覆盖：

1. PCG 参考输出、跨线程随机流一致性、取值范围及离散 CDF 的空/全零/大权重情况。
2. 10 万样本的几何映射解析矩和分桶频次。
3. Lambert 的 BSDF/PDF/吞吐一致性与方向反照率。
4. GGX 的解析空事件概率、法向分桶、倾斜方向的独立立体角积分、互易性、低粗糙度及掠射角。
5. GGX $F_0=1,\alpha=1$ 的反照率 $1-\ln2$。
6. 镜面离散质量，玻璃的 Fresnel/Snell、全反射、IOR 匹配及传输模式。
7. 面积光 Jacobian、双面发射、变换面积、BVH 命中 PDF 与混合光源 PMF。
8. 环境 PDF 归一化、常量图、亮点频次、双线性支持集、极点、旋转和负值 mip 抵消。
9. 环境资产引用、中文文件名、保存重开及不可变快照。

测试曾在极窄 GGX 波瓣下发现返回密度与公开 PDF 的方向归一化差异，已统一求值约定。环境分布还处理了负值 EXR 在 mip 中抵消的情况，确保原图仍发光时保留环境光源。

既有 GPU 综合回归通过：多方向光阴影、法线/深度、HDR/EXR、曝光、FXAA 和 resize 均通过。六次连续拖拽、两种窗口尺寸和侧栏恢复通过，最大测试 tick 间隔 89ms。各运行 Validation 为 0 errors。日志位于 outputs/a2.2-gpu 和 outputs/a2.2-interaction。
