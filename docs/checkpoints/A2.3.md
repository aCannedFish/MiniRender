# 积分验收

日期：2026-11-03。将 A2.1 求交和 A2.2 采样连接为 CPU 表面路径追踪器。

## 完成范围

- 迭代路径积分、发光面、环境、直接光照与多次反射。
- BSDF/Light/MIS 三模式、单样本 power heuristic、delta 事件处理。
- 俄罗斯轮盘赌、IOR 补偿、最大散射深度及查询统计。
- 薄透镜、孔径采样、焦平面与兼容旧场景的相机字段。
- CLI 分辨率、SPP、种子、深度、模式、曝光与 RR 参数。
- 线性 EXR 和显示 PNG，同一单像素内核供后续 UI/并行任务使用。
- CPU double 射线、命中误差与双端阴影偏移，Windows Unicode CLI 路径。

## 验证

CPU Debug、Release、desktop Debug、ASan/UBSan 均为 67/67 通过。CLI 测试包含中文和空格输出路径、小数曝光及非法曝光拒绝。macOS 14 初次 CI 暴露浮点 from_chars 缺失，现改用固定 classic locale 的浮点解析，并保留整数 from_chars；提交后继续要求两平台 CI 通过。

解析和回归测试涵盖：常量环境 Lambert、方向光、黑场景、自发光、深度 0、镜面、闭合玻璃、RR 均值、薄透镜焦点及确定性像素累计。有限阴影检查遮挡物位于光源前方或后方的区别，并覆盖整体缩放和大坐标平移。

旧 float 射线在 1000 个有限光源线段中产生 476 个错误终点遮挡，修复后为 0。多次反弹还复现了接近起点的数值自交，已通过三角形距离误差传播处理，保留了失败日志供本机核对。

## MIS 对照

每组 12 个种子，每种模式每个种子 2048 条路径，最大散射深度 1，RR 关闭。表中方差是各种子均值的样本方差；预算按路径条数定义，模式间阴影射线数量不同。

小面积光漫反射的参考值由独立面积积分计算，大面积光光滑导体的参考值由另一种子的 65,536 条 BSDF 路径计算。全部均值落在测试设定的五倍标准误差范围内。

| 场景 | 模式 | 均值 | 方差 |
| --- | --- | --- | --- |
| 小面积光/漫反射，参考 0.0426926 | BSDF | 0.0469401 | 8.40574e-5 |
| 同上 | Light | 0.0427122 | 2.38215e-9 |
| 同上 | MIS | 0.0427123 | 2.37416e-9 |
| 大面积光/光滑导体，参考 0.798497 | BSDF | 0.798599 | 7.06269e-7 |
| 同上 | Light | 0.813470 | 1.13909e-1 |
| 同上 | MIS | 0.798402 | 1.53029e-5 |

MIS 在两组中都降低了对应不适合场景的单一策略的方差；表中保留了全部三种结果。参数、种子和比较逻辑见 `path_tests.cpp`，本机记录为 outputs/a2.3/mis-statistics.log。

## 图像

```sh
build/macos-core-release/minirender_cli --render scenes/path-room.json outputs/a2.3/room --width 160 --height 160 --spp 128 --depth 12 --mode mis --seed 101
```

自建场景使用已有平面/方块资产，包含色墙、GGX 金属、理想玻璃和面积光。Apple M3、AppleClang 21、Release、单线程，本机运行为 3,276,800 条相机路径、8,003,132 条阴影射线、9,663,654 次散射，约 23.7 秒。图像与完整统计位于 outputs/a2.3/room.exr、room.png 和 room.log，不进入 Git。

Qt/Vulkan 综合回归、纹理 CPU/GPU 对照和连续拖拽回归均通过，Validation 为 0 errors。CPU 精度修改没有改变实时 GPU 数据布局。
