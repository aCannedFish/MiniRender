# 网格简化

日期：2026-11-09。此检查点接入 QEM 简化、属性保护、表面距离、Qt 后台任务与 LOD 保存。实现说明和代码阅读顺序见 [网格简化](../SIMPLIFICATION.md)。

## 完成范围

- 归一化平面二次型、10 个 double 系数、累计合并与局部坐标平移。
- 最优三维位置、线段最优位置、端点与中点候选，使用实际 float 位置检查合法性。
- 局部邻接、版本化最小堆、受影响边更新及失效元素清理。
- 流形边折叠、边界夹断与重复面检查、退化及局部翻转拒绝。
- 边界、UV 接缝、硬法线与几何折痕保护；连续 UV 插值和输出法线更新。
- 请求面数、实际面数、停止原因、最大已接受 QEM 代价。
- AABB 最近点查询、双向顶点/面重心采样距离及样本数。
- Qt 后台执行、阶段进度、取消、独立资产、撤销/重做及文件保存。

## 核心检查

新增 11 个测试用例，覆盖解析最近点、AABB 树与逐三角形查询对照、连续 UV、精确保留边界、闭合曲面、四面体重复面、边界夹断、属性接缝、目标受约束、代价上限、取消、大坐标、孤立位置、多分量与环面孔洞。

闭合测试从 256 面细分四面体请求 51 面，实际达到 50 面，Euler 数、边界环与分量数保持一致。环面与独立四面体联合输入的 Euler 数为 2，简化后维持两个分量与原孔洞。平面网格的采样距离低于 $10^{-12}$ 米，边界位置和连续 XY UV 保留。

Core Debug、Release 和桌面 ASan/UBSan CPU 回归均为 129/129。ASan 使用 `detect_leaks=0`，检查地址和未定义行为。

界面另检查代价上限和目标受约束两种停止原因。开启零代价上限后保留实际可达面数；对受保护的原 cube 请求 1 面时，面板显示约束原因并沿用原网格。简化后的地面阴影为 81/81 个遮挡点、3329/3329 个照明点匹配；直接受光曲面为 198/199。

中文路径 OBJ 导出与场景保存重开保持生成网格。79 万面网格在候选阶段取消，已有资产保持原样。原有几何回归继续检查共享资产、目标删除、场景切换、文件快照及运行中退出。完整 Release 同步验证通过，Vulkan 验证错误为 0。

## 复验命令

```sh
cmake --build --preset macos-core-release
ctest --preset macos-core-release --output-on-failure
build/macos-core-release/minirender_simplify_example
build/macos-core-release/minirender_simplify_example --stress
cmake --build --preset macos-desktop-release
python3 scripts/verify_gpu.py \
  build/macos-desktop-release/src/app/desktop/minirender_desktop.app \
  --scene scenes/studio.json --geometry-check --sync-validation \
  --output outputs/a4.3/release-sync --timeout 400
python3 scripts/verify_gpu.py \
  build/macos-desktop-release/src/app/desktop/minirender_desktop.app \
  --scene scenes/studio.json --geometry-check --timing-only \
  --output outputs/a4.3/release-timing-final --timeout 300
```

高精度输入及两个 LOD 的参考图、OBJ 和场景文件位于 `outputs/a4.3`，保持为生成产物。原始场景和模型不修改。Windows/NVIDIA 的桌面运行按 B 阶段复验。
