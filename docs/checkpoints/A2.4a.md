# 任务核心

日期：2026-11-03。本检查点完成 A2.4 的后台任务核心和 CLI 接入，后续 A2.4b 接入 Qt/Vulkan。

## 完成范围

- 异步准备、tile 多线程采样、可配置线程数与提交批次。
- 明确的准备/运行/暂停/取消/整理/完成/失败状态。
- 已记录样本数、完成像素、耗时、任务编号及统计归并。
- 不可变的部分/最终图像，非阻塞预览与预览尺寸限制。
- 准备、遍历及路径过程的协作取消，安全收回线程。
- CLI `--threads/--tile/--batch`，使用同一任务核心报告进度和导出。

## 验证

CPU Debug、Release、desktop Debug、ASan/UBSan 均为 75/75 通过。ThreadSanitizer 的任务测试 8/8 通过，无数据竞争报告。

```sh
cmake --build --preset macos-core-release
ctest --preset macos-core-release
build/macos-core-release/minirender_tests '[session]'
```

测试覆盖：

1. 1/3/4 线程、不同 tile 与批次，逐像素与串行 `PathTracer::render` bitwise 一致。
2. 暂停停稳后记录数冻结，快速恢复/再次暂停无死锁，恢复后保持串行结果。
3. 取消准备/排队任务、循环取消重启、暂停任务析构后收回线程。
4. 构建/查询/路径的取消传播，算法失败与取消区分，失败后重新启动。
5. 工作线程持续提交时读取预览，检查归一化、单调计数、有限值和旧快照不变。
6. 一个 tile 中先出现合法样本、随后图像范围溢出，验证不会发布半个失败批次。

## 图像对照

同一 `path-room` 场景，64×64、32 SPP、深度 8、MIS、种子 303，对照 1 与 4 个工作线程。两次输出的 PNG 和 EXR 二进制内容完全一致，均为 131,072 条路径，阴影/散射及几何测试统计相同。

一次 Apple M3 Release 运行记录为单线程约 606ms、四线程约 222ms。参数和日志位于 outputs/a2.4a。自动线程数保留一个 CPU 核，不将这一组结果作为其他设备的速度保证。
