# 离线界面

日期：2026-11-03。完成 Qt 离线任务控制、Vulkan 图像显示及 A2 本机验收。

## 完成范围

- 离线参数面板、启动/暂停/恢复/取消、实际样本进度、阶段和耗时。
- 固定任务快照，场景/相机/参数修改后的过期提示。
- 部分/最终结果后台导出，EXR 保留线性值，PNG 使用点击导出时的曝光。
- Vulkan float32 纹理、同尺寸上传缓冲复用、等比例显示与黑色留边。
- 实时/离线显示切换复用设备、交换链和实时网格缓存。
- 薄透镜光圈半径与对焦距离控件，曝光调整不重新采样。
- 独立 UI 控制器与显示实现，学习文档和真实窗口回归入口。

## 运行证据

Apple M3 上，desktop Debug 和 Release 的 CPU/CLI 测试均为 75/75。GPU 诊断、离线任务、相机交互、纹理过滤、线框和参数响应回归均通过，Vulkan validation 为 0 错误。

离线回归覆盖暂停计数冻结、恢复、取消及连续重启、完整/中间导出、Unicode 路径、窗口缩放、过期状态和返回实时预览。384 个显示像素探针对照 CPU Reinhard/sRGB 变换，逐通道误差不超过 2/255。最终 GUI 回归中的 Qt heartbeat 最大间隔为 Debug 235ms、Release 155ms，测试在 500ms 阈值内通过。

UI 使用 2 个线程、CLI 使用 3 个线程，在同一保存的快照上渲染 24×16、8 SPP、MIS、深度 6、种子 19、RR 深度 3，PNG 曝光为 0.75 EV。完整 EXR 与 PNG 二进制完全一致：

| 文件 | SHA-256 |
| --- | --- |
| EXR | `50376cc738021e280b159a2ed5f48fe66123edb6f1b356c23e07b5fec78cc724` |
| PNG | `8b9b8400e01b666ea829012d927db546e3588a65bf38df0b4420b3ed1ab232bb` |

Unicode 对照位于 `outputs/a2.4b/离线 回归02`，最终两种构建的图像和日志位于同级 `debug-final`、`release-final`。CPU 串行一致性、MIS 统计与多线程检查见 A2.3、A2.4a 的记录。

20 万三角形场景的 14 项参数回归，最长 UI 回调约 0.94ms，下一帧最长 97ms，普通编辑未重新上传网格或重建描述符。相机回归完成 6 轮程序内 Qt 拖拽、释放/捕获恢复和两种窗口尺寸检查，最大 tick 间隔 136ms。性能数据对应本机一次运行。

另通过原生界面打开 `path-room.json`，启动 256×256、64 SPP 的任务，点击暂停和恢复，检查最终计数 4,194,304/4,194,304，并通过文件对话框导出 PNG。面板布局无字段遮挡。原生拖拽路径仍以程序内 Qt 事件回归为证据。

## 复验

```sh
cmake --build --preset macos-desktop-debug
ctest --preset macos-desktop-debug
python3 scripts/verify_gpu.py build/macos-desktop-debug/src/app/desktop/minirender_desktop.app --scene scenes/path-room.json --offline-check --output outputs/offline --timeout 65
```

使用及源码阅读顺序见[离线界面](../OFFLINE_UI.md)。Windows 桌面和 NVIDIA/OptiX 运行时仍按 B 阶段验证，本次 GPU 证据均来自 macOS/MoltenVK。
