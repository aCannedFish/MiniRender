# SPPM 界面

日期：2026-11-11。A7.4 在既有离线面板中加入 SPPM，并提供两个焦散快速导入模板。操作见[离线界面](../OFFLINE_UI.md)，算法见[渐进光子映射](../SPPM.md)。

## 完成范围

- Path Tracing/SPPM 选择，共用分辨率、深度、随机种子、RR 和线程设置。
- SPPM 迭代次数、每轮光子数、初始半径、α 和内存预算。
- 完整迭代总进度，以及相机、建表、光子和统计更新的阶段进度。
- 已发射光子、合并贡献、半径范围和工作缓冲估算。
- 暂停回滚说明、同任务恢复、取消、旧场景快照和后台图像导出。
- 针孔相机、活动介质和内存不足的页内错误提示。
- 玻璃焦散和镜中焦散模板，保留原有七个模板的编辑与导入行为。

此前 `OfflinePanel::set_settings/start` 只保存四个旧积分器字段。现在完整保留后端和 SppmOptions，控件只修改用户编辑的字段。未编辑的 double 参数和字节预算保留原精度。运行中冻结设置，统计和图像继续对应启动时的任务。

## 核心检查

Release 266/266 项通过，ASan/UBSan 266/266 项通过。新增模板检查读取实际随包 JSON，检查玻璃、针孔相机、无介质、有限图像及非零焦散贡献；镜面模板还检查两侧含 delta 的 SDS 贡献。

生成脚本重新执行后，15 份已有场景和自有 OBJ 的字节完全一致。

## 界面检查

`--sppm-check` 在隐藏窗口中操作真实控件。普通构建开启响应阈值检查，ASan/UBSan 构建开启 Vulkan 同步验证。两组退出码均为 0，最终 Vulkan 验证错误均为 0。

| 构建 | 响应采样 | 最大延迟 | 取消等待 | 运行中退出 |
| --- | --- | --- | --- | --- |
| Release | 161 | 53ms | 199ms | 25ms |
| ASan/UBSan | 302 | 125ms | 199ms | 19ms |

高精度参数和非整 MiB 预算经过单字段修改、后端往返后逐值保持。64 轮、每轮 10000 光子的旧快照实际发射 640000 光子，暂停期间修改玻璃球位置、材质并保存重开，恢复后的图像与独立串行参考 RGB 最大误差为 0。新快照 8 轮、每轮 2000 光子的图像和统计也与参考一致。

GPU 显示分别检查旧图 576、新图 256 和曝光图 256 个像素。修改 EV 保持同一任务和样本计数，EXR 保留线性值。切回 PT 后的图像同样与独立 PathTracer 一致。

1200×800 和 960×700 两种窗口尺寸检查 27 个离线控件的边界、遮挡和底部阶段进度的滚动可达性。截图经过检查。非针孔相机与介质被明确提示，场景和后端保持用户设置；内存预检失败也显示在面板中。

## 关联回归

九个模板在普通构建和 ASan/UBSan＋同步验证中均通过，完成覆盖导入、参数建议、手动编辑、历史、保存重开、模板字节保护和独立积分器比较。原有 PT 离线、体积、布料播放、相机拖拽和参数更新回归均通过，所有进程最终 Vulkan 验证错误为 0。体积响应最大 67ms，布料编辑响应最大 33ms，相机六次拖拽最大间隔 68ms，14 次参数操作未重建网格或描述符。

## 复验

```sh
cmake --preset macos-desktop-release
cmake --build --preset macos-desktop-release --parallel 4
ctest --preset macos-desktop-release --output-on-failure
python3 scripts/verify_gpu.py \
  build/macos-desktop-release/src/app/desktop/minirender_desktop.app \
  --scene scenes/studio.json --sppm-check --timing-only \
  --output outputs/a7.4/ui --timeout 240
python3 scripts/verify_gpu.py \
  build/macos-desktop-release/src/app/desktop/minirender_desktop.app \
  --scene scenes/studio.json --presets-check --sync-validation \
  --output outputs/a7.4/presets --timeout 240
```

日志位于 `work/sppm-ui-*.log`，图像和可编辑测试场景位于 `outputs/a7.4`。自动测试使用隐藏窗口，不激活或置顶。
