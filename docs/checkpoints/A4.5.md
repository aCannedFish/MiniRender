# 自适应细分

日期：2026-11-09。A4.5 接入误差驱动的 Loop 与高度位移，包含按需有限层参照、red 层级、邻接平衡、终端过渡、局部米制/固定像素误差，以及 Qt 后台任务。参数与代码阅读顺序见 [自适应细分](../ADAPTIVE.md)。

## 完成范围

- 虚拟均匀 Loop 的共享点 ID、一环、有限 even 递推、odd 规则和面积法线。
- 误差优先队列、相邻叶子层级差约束及 0/1/2/3 条分裂边的终端模板。
- 实际终端三角形的误差复查、连续高度与 texel 特征检查、完整 UV 接缝检查。
- 参照最大层级不足时报告未达目标，面数与求值预算失败时保留原场景。
- 几何页参数、阶段进度、取消、各层面数、实际容差与采样误差。
- 独立网格资产、撤销/重做、旧离线快照、OBJ 与场景往返。

## 核心检查

新增 11 个用例。虚拟层级与已有均匀 Loop 实际输出逐层对照，覆盖 3/4/5/6/9 价数扇形、开放边界和闭合 cube，核对位置、邻接、一环方向及法线。还检查孤立位置、单点高层求值、非法查询、预算和取消。

自适应测试包括平面、曲面、强制均匀层级、局部高度特征、UV 边内部接缝冲突、固定视图尺寸、透视、镜像变换与靠近相机的几何。取消覆盖拓扑、接缝、采样、细化、平衡、过渡、法线、输出及完成阶段。

输出通过有向半边拓扑检查，输入/输出 Euler 数、边界环、面分量及孤立位置数量一致。局部高度测试使用独立的实际 6 层均匀 Loop 与位移结果，遍历密集顶点和面重心检查最近表面距离，并验证输出点落在对应参照位置附近。

Core Release 与 ASan/UBSan 回归均为 164/164，通过。core 与 desktop 的 Debug/Release 编译数据库均包含新增核心、测试和桌面模块，桌面 Debug 命令包含实际 Qt 头文件目录。

真实几何控件对蓝色 cube 执行自适应细分。以最大层级 4、目标 0.01 米生成 736 面，报告最大采样误差 0.00970733 米，236 次 red 分裂、28 个非标准过渡面、1538 个求值虚拟点；输出按所属叶子统计为 L2=32、L3=704。

撤销/重做逐像素恢复对应图像。共享原网格的另一个 cube 保留原资产。启动后修改目标误差和粗糙度，任务仍使用启动参数，生成结果保留材质编辑。像素模式启动后移动相机，核心对照确认采用启动时的投影矩阵与视口尺寸。

旧离线任务使用原网格快照，结果显示过期；新任务使用生成几何。两次 24×24、16 spp、seed=101、深度 5 的任务均与独立串行路径追踪逐像素一致。中文路径 OBJ 导出和场景保存重开保持生成几何。

输入预算不足会禁用生成，细化时预算失败保留原资产。高层任务在细化/平衡阶段通过实际取消按钮中止，回调在两秒内返回，随后立即启动新任务并退出以检查线程清理。测试等待面板刷新并确认取消请求已发出。

## 响应检查

普通计时与 Vulkan 同步验证分开运行。独立线程每 20ms 投递事件，统计 Qt 主线程排队时延。显式 CPU 参考计算和 GPU 读回暂停计时，控件操作、后台任务、结果发布及等待期间继续计时。全部回归隐藏窗口，不主动激活。

自适应流程记录 185 个事件，最大排队时延 339ms，运行中退出清理 27ms。原有完整几何流程记录 1256 个事件，最大排队时延 328ms、定时器间隔 519ms，退出清理 44ms。两项均通过原有 500ms 事件时延阈值。

此前高负载运行记录完整几何流程 4883ms，已安装的上一版同样在相同流程中记录 541ms，均超出阈值。日志保留在 `work/adaptive-regression-timing.log` 与 `work/adaptive-baseline-timing.log`。上述复测通过，阈值保持原值。

Release 与 ASan/UBSan 桌面同步验证的错误数均为 0。最新插桩桌面运行中退出清理 44ms，启用 `-O1`、`detect_leaks=0:abort_on_error=1` 和 `halt_on_error=1`。C++、Objective-C++ 与源码 Catch2 使用相同插桩配置。插桩流程不执行普通响应时间阈值验收。

应用更新采用 `scripts/install_macos.py`，部署并验证依赖后替换 `/Applications/MiniRender.app`，清理旧应用包。源码、结果与构建缓存保留。

## 复验

```sh
cmake --preset macos-core-release
cmake --build --preset macos-core-release
ctest --preset macos-core-release --output-on-failure
build/macos-core-release/minirender_adaptive_example
cmake --preset macos-desktop-release
cmake --build --preset macos-desktop-release
python3 scripts/verify_gpu.py \
  build/macos-desktop-release/src/app/desktop/minirender_desktop.app \
  --scene scenes/studio.json --adaptive-check --timing-only \
  --output outputs/a4.5/adaptive-timing --timeout 300
python3 scripts/verify_gpu.py \
  build/macos-desktop-release/src/app/desktop/minirender_desktop.app \
  --scene scenes/studio.json --adaptive-check --sync-validation \
  --output outputs/a4.5/full-gui --timeout 300
```

测试结果、图像和生成资产保留在 `outputs/a4.5` 与 `work`。Windows/NVIDIA 桌面验证按 B 阶段执行。
