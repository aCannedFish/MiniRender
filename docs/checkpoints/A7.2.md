# 介质界面

日期：2026-11-11。A7.2 接入介质参数页、三个体积模板与 Qt 离线任务入口。操作和代码阅读顺序见 [介质界面](../VOLUME_UI.md)，积分模型见 [体积散射](../VOLUME.md)。

## 完成范围

- 区域选择、新增、删除、名称、启用状态、世界边界、RGB 系数和 g。
- 草稿校验、一次应用历史、撤销/重做及未编辑 double 参数保留。
- 后台场景保存重开、新文档草稿同步及旧离线快照隔离。
- 有界雾、Cornell Box 雾、透光孔光束三个随包模板和快速导入。
- 任务入口、真实进度、取消、曝光和 Vulkan 结果显示。
- 模板生成脚本、核心数据检查、真实控件与布局回归。

## 核心数据

独立 CPU-only Release 与 ASan/UBSan 回归均为 249/249 项通过。新增模板专项为 2 个用例、2328 个断言，检查三个模板的独立期望结构、参数、有限像素和实际体积事件。

透光孔几何通过独立射线检查：孔内竖直射线到达地面，孔外射线在 y=2.6m 处命中顶板。模板预期物体数量分别为 3、8、2。

生成脚本重跑后，七个模板、球体、顶板及其他被检查场景共 13 份文件的字节保持一致。模板和几何由项目生成，随应用部署。

## 编辑历史

隐藏 Qt 窗口通过真实按钮和字段执行新增、参数应用、删除与撤销/重做。非法盒和启用区域重叠均显示页内诊断，文档保持原值；关闭区域后允许保存重叠，重新启用时再次验证。

将字段改回原值后，草稿标志清除。未应用改动使开始入口等待应用；已有任务的查看入口保持可用。参数应用各形成一次历史，完整区域集合一起校验。

相机和材质编辑保留未应用草稿。高精度边界、吸收系数和 g 从文件载入后，只修改散射的一个通道，其他 double 值逐值保持。后台保存重开后数据一致；重新打开含相同介质的文件也会重置上一文档的未应用草稿。

## 任务成像

启动 32×32、256 spp、seed=101、深度 6、2 线程任务后立即修改介质。旧任务仍使用原快照，过期标记生效，查看入口保持同一 job ID。完成图像与启动时的独立串行路径追踪逐像素一致，最大 RGB 向量误差为 0。

重新以当前场景启动 16×16、32 spp 任务，过期标记清除，结果与新快照的独立串行图像一致，最大误差为 0。两次图像均记录实际体积散射。

## 预置导入

全部七个模板通过真实快速导入动作验证。回归按源模板的完整对象集合、变换、材质引用和介质参数检查覆盖结果，继续编辑物体、材质、面积光或方向光与相机，再保存重开和离线渲染。

每个模板的任务输出与独立串行参考逐像素匹配。修改与保存过程中，包内模板字节保持原值；旧任务运行时导入下一模板，可以异步取消并应用新建议。

七模板流程同时通过普通 Vulkan 同步验证和 ASan/UBSan 同步验证，最终验证错误均为 0。

## 布局响应

1200×800 与 960×700 检查覆盖 23 个命名控件，验证横向边界、控件重叠和应用按钮可达性；顶部和底部截图已检查。数值显示省略小数尾零，完整场景值放在工具提示中。

普通 Release 完整介质流程记录 142 个事件，最大排队时延 73 ms，保留 500 ms 阈值。12 次实际介质应用没有网格上传或描述符重建。运行中的体积任务取消为 49 ms，带任务退出的窗口、线程和 GPU 清理为 11 ms。

ASan/UBSan 完整流程记录 226 个事件，最大 198 ms；取消 51 ms、运行中退出清理 38 ms。Vulkan 同步验证错误为 0，进程正常退出。参考计算、测试夹具生成和 GPU 读回单独排除出响应统计，生产编辑、文件任务和任务发布保持计时。

相机交互、参数、操纵器、纹理、布料播放、SSAO 和表面朝向七组回归均通过，最终 Vulkan 错误为 0。参数 14 项操作没有网格或描述符重建，最大回调 0.628 ms、下一帧 61 ms；相机完成六次拖拽，最大定时器间隔 66 ms。布料深入编辑最大排队 38 ms。
