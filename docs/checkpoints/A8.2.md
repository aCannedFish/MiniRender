# 光场工作台

日期：2026-11-12。右侧光场页支持采集、子视图查看、重聚焦、文件读写和图像导出。“快速导入”新增可编辑的近远棋盘。操作及代码入口见[光场界面](../LIGHT_FIELD_UI.md)。

## 图像验证

从随包场景采集 64×64、32 spp、5×5 视图，seed 为 101。相机前方 2m 和 6m 各有一块棋盘。以棋盘内部相邻像素的梯度衡量清晰度，近红棋盘在近焦时为远焦时的 8.71 倍，远蓝棋盘在远焦时为近焦时的 9.67 倍。切换焦点、孔径与子视图后，采集计数保持 3276800。

回归用独立 reader 计算参考图，再检查视口读回的像素。连续调整焦距时采用最后一个请求，网格和描述符的上传计数保持不变。切到后台的 PT 继续渲染，显示光场时工具栏导出的 EXR 与光场结果一致。切回 PT 可取回原任务的进度和图像。

## 文件与交互

回归覆盖中文及空格路径的保存和重开、线性 EXR 与带曝光的 PNG 导出、打开损坏文件时保留旧数据和当前视图。暂停采集后编辑场景会提示快照过期；恢复采集仍使用启动时的相机与场景。取消和关闭窗口均等待后台资源安全释放。

在 1200×800 和 960×700 两种窗口尺寸下检查 34 个控件的位置与滚动可达性。普通构建记录 167 个响应间隔，最大 90ms，取消耗时 165ms，退出清理 6ms。ASan/UBSan 与同步验证同时启用时，最大间隔 151ms，取消 98ms，退出清理 22ms。验证层报告 0 个错误。以上为 Apple M3 上的单次测量。

## 回归

CPU-only Release 和 ASan/UBSan 各通过 298 项测试。新增的场景测试从实际资产采集近远棋盘并检验两个焦点。普通构建与 ASan/UBSan 构建均通过全部 14 个模板的隐藏窗口同步验证。

离线渲染、SSS、SPPM、体积、布料播放、相机拖拽、参数编辑、SSAO 和表面朝向使用既有专项脚本复验。光场独立脚本命令见[界面复验](../LIGHT_FIELD_UI.md#复验)。调试与发布的编译数据库均包含新增的面板、控制器、交互检查和场景测试。
