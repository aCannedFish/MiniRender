# A1.3 验收

日期：2026-11-02。范围：方向光深度图阴影及 PCF。本机阶段和 A1 整体仍在进行。

## 已完成

- 根据世界空间场景范围拟合稳定方向光正交投影。
- 最多八层的 D32 阴影数组、每层深度 pass、主 pass 遮挡查询。
- shader 显式深度比较、3×3 PCF、depth bias，支持 MoltenVK 的基础采样能力。
- 相机面板的阴影开关、双方向光测试场景和 CPU/GPU 遮挡对照。
- FrameUniform 的 GLSL 共享定义，CPU/GLSL 布局静态断言。

## 验证结果

| 项目 | 结果 |
| --- | --- |
| Desktop Debug CTest | 17/17 通过 |
| Core Release CTest | 17/17 通过 |
| 单光源阴影开关 | 1,882 像素变暗 |
| 双光源，隔离第二盏灯 | 74,860 像素变暗 |
| 第二层 CPU/GPU 遮挡对照 | 遮挡 127/127，受光 982/982 一致 |
| 图像操作回归 | 编辑、撤销、重做、保存重载、法线、相机、复制/删除通过 |
| Vulkan Validation | 单灯与双灯均为 0 errors，包含资源释放 |

最初的比较采样器触发 portability 能力错误，已改为 GLSL 中的普通采样加深度比较，并重新运行验证。没有将失败的运行计为通过。

原始图像/日志由 SHADOWS.md 的命令生成到 outputs/a1.3 和 outputs/a1.3-multi。记录包括 shadow-on.png 和 shadow-off.png。

HDR 离屏、独立后处理、FXAA、线框/深度视图及后续课程选题尚未完成。远端 CPU CI 在 push 后运行，Windows/NVIDIA GPU 留待 B 阶段。
