## 图像对照

解析球的法线和深度各检查 24042 个命中、47853 个未命中样本。预期值直接由二次方程和球法线计算，避开判别式绝对值小于 0.05 的轮廓样本。

复杂场景使用 CPU 参照图选择稳定邻域，每种视图再与实际 GPU 浮点读回比较。参考图要求至少 1000 个表面像素，避免空图通过检查。

| 法线 | 73649/73649 | 0.000485261 |
| 深度 | 74180/74180 | 0.00000825906 |

| 交集内部起点 | 74502/74502 | 0.000202238 |

步数模式容许 float 与 double 在阈值附近相差少量迭代，颜色阈值为 0.02；其余颜色阈值为 0.003，深度为 0.00005。独立单步预算场景中，6545 个样本均为耗尽状态的品红色。

所有视图另以浮点值计算显示变换，再与实际 sRGB 图像逐通道比较，允许 2 个 8-bit 量化单位。表面对照使用曝光 1，浮点结果仍与无曝光 CPU 光照一致。

放大图像时发现示例切割盒的上表面与球顶相切，导致顶部残片和异常阴影点。切割盒保持原底面，向上增加 0.1 m 的余量；新增球顶距离界用例，实际图像已重新检查。更新后的四张 256×256 CPU 图均为 36191 次命中、726776 次求值、0 次耗尽和 0 次梯度回退。

## 布局与响应

两种窗口尺寸都检查 48 个可见命名控件的边界、交叠和底部滚动可达性。启用页签滚动按钮后，新增距离场页仍可在 960×700 使用。程序切换视图时，下拉框和阴影勾选同步更新。实际上下滚动截图已检查。

30 轮位置、灯光、视图与阴影修改期间，普通 Release 探针记录 119 个事件，最大排队时延 73ms，通过 500ms 阈值。参考计算和图像读回单独计时，实际控件、文件操作和参数发布保持测量。

完整 ASan/UBSan 界面流程通过，包括文件、图像、历史和正常退出。探针记录 62 个事件，最大时延 133ms，Vulkan 同步验证错误为 0。回归工具的探针统一由 Qt 父对象持有，避免重复释放。
