# 布料播放

日期：2026-11-11。A6.3 将模拟核心、微圆柱材质、场景历史和动态 Vulkan 网格接入桌面界面。操作与代码阅读顺序见 [布料播放](../CLOTH_UI.md)。

## 完成范围

- 落球、悬挂迎风两个可编辑场景，支持覆盖与撤销。
- 播放、暂停、单步、重置、参数草稿、进度与计算统计。
- 局部状态、世界外力、非均匀/镜像变换与恢复计算。
- 物体移动/旋转，碰撞体开关、摩擦及变换同步。
- 状态保存重开、单次参数历史、冻结网格及离线快照。
- 后台计算与网格准备、来源检查、取消与运行中退出。
- 顶点缓冲复用与共享静态网格保护。

## 核心检查

Release CPU-only 与 ASan/UBSan 均为 228/228 项通过。新增组件专项为 8 个用例、167 个断言，覆盖仿射变换、精确固定点、解析自由落体、共享资产、瞬时帧历史、手势冲突、文件恢复及碰撞体参与条件。

文件检查拒绝负数或分数帧、溢出/分数网格尺寸、非法固定点、缺失速度、零子步，以及状态与 OBJ 不一致的情况。组件还检查非有限状态、固定点移动、拓扑和 UV 改动。已保存的状态位置和速度逐值相同，从相同重开状态继续计算的结果一致。

JSON 文件与 OBJ 资产保存完整模拟配方和显示网格。普通核心构建保持 Qt、Vulkan 和 CUDA 关闭。

## 编辑检查

隐藏窗口中的真实按钮流程包括播放至多帧、暂停、单步、重置、撤销/重做、后台保存与后台打开、冻结与恢复。UI 单步的位置和速度与独立核心计算逐值相同，暂停后没有新帧发布。

真实鼠标事件拖动移动轴和旋转环。开始手势暂停物理，拖动期间保持同一组件，提交后从新变换恢复；接续单步与独立世界空间计算逐值相同。播放中编辑相机与材质，模拟继续推进。

网格改为 17×13、固定上边整行、面密度 0.25 kg/m²、Z 风速 0.8 m/s 后应用，状态恢复到新静止网格。一次撤销恢复旧姿态，一次重做恢复新网格，后续单步仍与独立核心计算相同。

关闭球体碰撞后，环境不再包含该球；摩擦修改为 0.7 后重新启用并移动球体，播放至至少 90 帧产生实际接触，所有粒子均在球面外。切换模拟目标并冻结副本，原布料保持可模拟。

## 成像检查

普通 Release 的 CPU/GPU 法线与深度对照如下：

| 状态 | 匹配采样 |
| --- | --- |
| 暂停姿态 | 2735/2735 |
| 数值变换后 | 2725/2725 |
| 移动与旋转手势后 | 2326/2326 |
| 动态布料与静态共享副本 | 2686/2686 |

播放帧数由后台调度决定，不同验证构建的采样数量随暂停姿态略有变化。ASan/UBSan 中各组也通过相同误差阈值。

播放时启动 16×16、8 spp、seed=101、深度 4、2 线程的离线任务，模拟立即暂停。任务完成后组件仍为启动时的可见帧，迟到模拟结果未被应用。离线结果逐像素与启动时独立串行路径追踪参考一致，RGB 向量误差小于 $10^{-6}$。恢复播放后，旧离线结果标为过期。

## 缓冲检查

初次显示后的普通播放帧只更新顶点数据，缓冲分配和索引上传次数不增加。复制并冻结一个仍使用旧网格的可见物体后，原布料下一帧恰好增加一次缓冲分配。再下一帧继续复用新缓冲，索引上传次数保持不变。CPU/GPU 图像检查同时包含原布料与静态副本。

## 布局响应

1200×800 与 960×700 的表单检查覆盖 44 个直接字段，验证水平边界、行间遮挡与底部滚动可达性。顶部播放按钮和底部参数截图已检查。载入示例、播放、单步和重置会返回实时场景，避免继续显示先前的离线结果。

普通 Release 的基础流程记录 56 个事件、最大排队时延 54 ms；深入编辑记录 180 个事件、最大 25 ms。检查保留 500 ms 阈值，独立参考计算与 GPU 读回暂停计时。保存和打开使用实际后台入口。

128×128 网格、4096 子步的真实任务在推进阶段取消，99 ms 返回且保留原组件。运行中删除目标、撤销删除和覆盖场景均丢弃旧结果。带任务退出时，窗口、后台任务和 GPU 资源清理为 43 ms。

最终 ASan/UBSan 完整流程包含上述操作、取消与运行中退出，事件最大时延 119 ms、取消 49 ms、退出清理 64 ms。Vulkan 同步验证错误为 0，进程正常退出。

既有操纵器、参数、纹理、表面朝向、布料材质、场景编辑、SSAO 与相机交互回归均通过，全部正常退出且 Vulkan 验证错误为 0。参数回归的 14 项操作没有网格或描述符重建，最大回调 0.514 ms、下一帧 60 ms；相机完成六次拖拽，最大定时器间隔 69 ms。安装器的 9 个 Python 用例通过。

## 复验

命令见 [布料播放](../CLOTH_UI.md)。本机日志位于 `work/cloth-playback-*`，图像和状态文件位于 `outputs/a6.3`。普通流程使用 `release-final`，最终插桩流程使用 `asan-complete`。编译数据库包含新增核心和 Qt 模块。

Windows CPU 兼容性由 CI 检查；Windows/NVIDIA 桌面与设备性能按 B 阶段验收。
