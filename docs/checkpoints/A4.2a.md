# 位移与导出

日期：2026-11-04。完成 A4.2a 的真实高度位移、接缝检查、OBJ 导出与生成资产保存。A4.2b 的 Qt 后台几何工具和实时资产替换仍待接入，A4 总体保持进行中。

## 完成范围

- 沿共享位置平滑法线执行局部米制位移，读取线性 R 高度，支持负高度/振幅。
- 共享顶点高度检查，以及边内部双线性高度差的分段二次极值检查。
- 面积、面朝向、有限位置、稳定法线、接缝扫描预算和协作取消。
- Loop 与位移共用的面积加权法线模块。
- 保留共享位置和独立面角属性的 OBJ 写出，中文路径和区域设置处理。
- 生成资产的内容命名/复用、冲突换名、场景最后提交和输入资产别名保护。
- 可取消的数据校验、记录/字节进度、旧目标文件与旧快照保护。
- 独立 CPU 示例，从细分/位移到写出、重开及同种子渲染。

位移测试覆盖解析平面偏移、错误硬法线、负值、UV 原点/Repeat/纹素中心、零振幅、顶点接缝、端点吻合但内部不连续的边，以及只有二次极值超过容差的接缝。后者两端和中点均不超过 0.15，内部最大差值为 0.16，容差 0.155 时正确拒绝。

测试还覆盖过长 UV 扫描的预算拒绝、无效设置、坐标溢出、翻面和各阶段取消。已有 BVH 查询的命中距离由 2m 变为 1.9m；固定有限阴影线段的遮挡从无到有，证明移动的是求交几何。

写出测试覆盖位置/UV/法线往返、非单位法线、中文及空格路径、小数点区域设置、预先/中途/提交前取消、已有文件和目录保护、生成资产复用、内容冲突、来源缺失、并发保存、输入路径/硬链接别名，以及撤销后的旧快照。暂存目录均在退出时清理。

## 示例结果

示例为 studio 场景、cube 三层 Loop、64×64 周期高度、scale=0.15m、midlevel=0.5。固定相机与光照，渲染 128×128、64 spp、seed=101，使用默认 MIS、深度 8 和 RR。

| 指标 | 结果 |
| --- | --- |
| 网格 | 386 个位置、768 个三角形 |
| 最大实际局部位移 | 0.0523736m |
| 接缝检查 | 48 条边、432 个区间，最大距离差为 0 |
| 轮廓变化 | 128×128 主射线中，57 个像素的命中实例/可见性改变 |
| 地面阴影变化 | 21 个地面采样点的方向光遮挡改变 |
| 导出/重开最大 RGB 向量误差 | 1.90735e-06，低于示例阈值 1e-5 |

轮廓和阴影计数由独立 BVH 可见性查询得到，未从含 Monte Carlo 噪声的像素差推断。位移前后及重开图像已目视检查。法线在 OBJ 写入/读取时归一化，因此重开渲染不要求逐位一致。

输出位于 `outputs/a4.2a`，含 before/displaced/reopened EXR 与 PNG、线性高度 EXR、独立 OBJ、JSON 和生成资产。原 studio 与输入 OBJ 未修改。

## 复验

```sh
cmake --build --preset macos-core-release
ctest --preset macos-core-release
build/macos-core-release/minirender_displacement_example
cmake --build --preset macos-desktop-debug
ctest --preset macos-desktop-debug
```
