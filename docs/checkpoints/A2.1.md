# 求交验收

日期：2026-11-03。本检查点实现 A2 的 CPU 场景求交基础，后续继续采样、材质、路径积分及任务控制。

## 实现范围

- 单位世界空间射线、闭区间和轴对齐包围盒 slab 查询。
- 射线主轴置换、剪切、双精度边函数与重心坐标。
- 12 桶 SAH BVH、平坦节点、近侧优先遍历和有界深度。
- 最近命中、有限距离遮挡、世界位置、几何/着色法线、UV 及场景索引。
- 只读场景共享、可选查询计数及并发只读访问。
- CLI `--trace-normals scene.json output.png`，输出 256×256 几何诊断和构建/遍历统计。

测试复现了合法大缩放下 float 逆转置溢出导致 NaN 的问题，修复为 double 中间运算。构建使用项目现有依赖，没有引入外部求交库或 Qt/GPU 依赖。

## 验证

```sh
cmake --build --preset macos-core-debug
ctest --preset macos-core-debug
cmake --build --preset macos-core-release
ctest --preset macos-core-release
build/macos-core-release/minirender_cli --trace-normals scenes/studio.json outputs/a2.1/studio-normals.png
```

本机 CPU Debug、Release、desktop Debug 的 CTest 均为 36/36 通过。另建 ASan/UBSan 的 CPU 配置，36/36 通过，无 sanitizer 报告。

新增检查包括：

1. 平行/反向射线、盒面起点、有限线段和闭区间端点。
2. 三角形重心坐标、背面求交、三种尺度的共享边/顶点、倾斜共享边和细长三角形。
3. 4,000 条固定种子射线，与独立的 double Möller–Trumbore 暴力求交比较最近距离、实例/三角形索引和遮挡。
4. 非均匀/镜像缩放、UV/平滑法线插值、正背面标记及快照不受编辑影响。
5. 空场景、重合重心、等距选择、首次命中提前返回、float 精度下的塌缩报告。
6. 四线程共享 BVH；64 个沿 X 分离的三角形，每条射线只经过一个叶子，图元测试不超过叶子容量上界。
7. CLI 完整加载、构建、主射线查询和 PNG 输出。
