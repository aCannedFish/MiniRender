# 拓扑与细分

日期：2026-11-04。A4.1 本机通过。本检查点完成半边与均匀 Loop 核心；A4 的位移、Qt 几何工具、简化、重网格和自适应细分仍按 [计划](../../PLAN.md) 推进。

## 完成范围

- 共享位置索引上的有向半边结构，显式边界半边与边界环。
- 数据、重复面、边面数、绕序和顶点面片扇检查。
- 边界/内部旧点与边点规则，原始 Loop 余弦权重。
- 每条共享边一个新位置，逐父面线性 UV，面积加权平滑法线。
- 最终面数与索引预算、实际阶段进度、协作取消和不可变结果。
- 局部父子面朝向、退化与稳定法线检查。
- 现有 OBJ、快照、BVH、路径追踪集成及可独立运行的 CPU 示例。

测试覆盖闭合四面体、开口面片、双边界环、独立重合面片、孤立位置、UV 接缝、3/4/5/6/7/11 度顶点，以及连续四层细分。四面体各层保持 Euler 数 2、无边界和单一连通分量；环形面片保持 Euler 数 0 与两个边界环。

解析检查包含边界坐标、内部边权重、度数 4 的中心系数 33/64、度数 6 的中心系数 5/8，以及平移/非均匀线性变换前后的细分一致性。两层带 UV 接缝的面片有 25 个位置、32 个三角形，接缝上 5 个共享位置保留两侧独立 UV，未被拆成几何边界。

错误输入覆盖无效数据、同向共享边、三面共享边、重复面、边界多个面片扇和两个闭合壳体仅共享顶点。输出错误覆盖面积门槛、狭长面片扇的局部翻转和重合折叠面造成的法线抵消。拓扑合法并不意味着嵌入几何没有自交，本检查点不做全局自交检测。

取消测试在每个阶段请求取消，并在顶点、边、面、法线扫描处理至少 1024 个单位后中止，输入和前一次结果均保持不变。预先取消、预算超限、空输入及 0 层返回原对象均有检查。

## 复验

在仓库根目录运行：

```sh
cmake --build --preset macos-core-release
ctest --preset macos-core-release
build/macos-core-release/minirender_loop_example
cmake --build --preset macos-desktop-debug
ctest --preset macos-desktop-debug
```

CPU CI 会在 macOS 和 Windows 上构建同一核心、测试与示例；合并前要求两个平台的 CPU 检查通过。Windows 桌面、DPI 和 NVIDIA 验证仍属于 B 阶段。

数据约定、公式、代码阅读顺序及原文来源见 [网格处理](../GEOMETRY.md)。
