# 快速导入

日期：2026-11-09。工具栏增加“快速导入”，提供四个可编辑的离线场景，使用说明见 [内置场景](../BUILTIN_SCENES.md)。

## 完成范围

- 经典 Cornell Box、玻璃与金属、材质球阵列及小光源场景。
- 场景使用自建几何、相机、单面墙壁/面积光和闭合玻璃球。
- 覆盖当前场景，通过正常 SceneEditor 保留完整编辑能力。
- 配套分辨率、spp、深度和种子，渲染手动启动。
- 异步取消旧离线任务、隐藏旧预览并在结束后应用新建议。
- 内置模板作为副本打开，编辑后保存到用户路径。

## 检查结果

Core Release 153/153，通过。新增用例读取全部场景、检查有效发光面、有限且非黑的实际渲染，并验证球体的闭合拓扑、绕序和径向法线。

Qt/Vulkan 完整回归通过：菜单动作启动后台读取；旧对象被覆盖；物体移动、撤销/重做、材质粗糙度、面积光自发光和相机位置均可修改；中文路径保存重开后保留修改，模板字节保持不变。

每个场景使用 24×24、16 spp、seed=101、深度 8，与独立串行 PathTracer 逐像素比较，最大容差 $10^{-6}$。旧任务运行时快速导入下一个场景，异步取消和新建议参数均通过。Vulkan 同步验证错误为 0。

另外生成四张 192×192、64 spp、seed=101、深度 12 的实际离线图，确认 Cornell 布局、红绿墙、玻璃、金属反射、粗糙度差异和小光源结果。原始 EXR、显示 PNG 和日志保留在本地 `outputs/presets` 与 `work`。

ASan/UBSan 桌面回归通过，使用 C++/Objective-C++ 的 address、undefined 插桩和 `-O1`，同步验证错误为 0。小光源自发光值超过原控件上限 100，控件范围已扩展到 1000000，并由编辑保存回归覆盖。Windows CPU 行为由 PR CI 复验，Windows/NVIDIA 桌面仍按 B 阶段执行。
