# 本机验收

本次基线包含 11 个课程选题。CPU 渲染和几何核心可以单独构建。桌面使用 Qt Widgets 与 Vulkan，在 Apple M3 上通过 MoltenVK 运行。Windows/NVIDIA 的实机任务见[设备迁移](../WINDOWS_HANDOFF.md)。

## 综合场景

[下载场景与参考图](https://github.com/aCannedFish/MiniRender/releases/download/macos-baseline/minirender-macos-references.zip)，解压后用“打开场景”选择 `showcase/showcase.json`。左侧金属环面来自 5000 点的球旋转重建，中间亚麻布是布料模拟第 90 帧，右侧蓝色模型来自三层 Loop 细分与高度位移。四个对象共 11922 个三角形，资产路径均相对于场景。可移动环面、修改布料材质，或关闭有界雾比较离线图像。布料在这份场景中保存为冻结网格。

从仓库根目录也可以用 CPU 示例重建它：

```sh
cmake --preset macos-core-release
cmake --build --preset macos-core-release --parallel 4
build/macos-core-release/minirender_point_cloud_example
build/macos-core-release/minirender_cloth_material_example
build/macos-core-release/minirender_displacement_example
python3 examples/showcase.py
build/macos-core-release/minirender_cli --render outputs/a9/showcase/showcase.json outputs/a9/showcase/reference --width 512 --height 288 --spp 512 --depth 6 --mode mis --seed 501 --threads 4
```

高采样图使用 4 个 CPU 工作线程，累计 75497472 条相机路径和 13610797 次介质散射。M3 Release 单次渲染耗时 89.8 秒，进程峰值常驻内存约 20.1 MiB。另附一张 320×180、128 spp、seed=101 的预览。两者都保存了线性 EXR 与显示 PNG。

## 参考文件

压缩包含 75 个文件，共 9027012 字节。SHA-256 为 `7b146244f29c871421abe302346476c49cbd4d0a23a95c9948ab3c6d00e952e6`。可用 `shasum -a 256` 或 PowerShell 的 `Get-FileHash -Algorithm SHA256` 检查下载文件。[逐文件清单](../baseline/reference-manifest.json)记录了解压后的文件名、大小与 SHA-256。各项素材为项目自建示例；图像保存在 GitHub Release 中。

比较图像时，先对齐分辨率、相机、积分器与曝光。线性 RGB 的通道 RMSE 为所有像素、三个通道的平方误差均值开方。对重建几何使用点到表面的双向采样距离。参考图用于跨平台比较，压缩文件的哈希用于检查文件完整性。

## 复验环境

环境为 Apple M3、Apple Clang 21、MoltenVK 1.4.2，具体依赖与构建命令见[构建说明](../BUILD.md)。CPU-only Release 关闭桌面和 OptiX；桌面 Release 关闭 OptiX。隐藏窗口回归检查视口不会激活。CPU 的 298 项测试在 Release 和 ASan/UBSan 配置下均通过。

GPU 检查覆盖基础绘制、场景、纹理、线框、移动/旋转、几何、自适应、点云、SDF、IBL、SSAO、布料、体积、SPPM、SSS、光场、离线任务和 14 个模板。计时专项单独关闭验证层；同步检查显式启用 Vulkan 验证层。完整命令入口为 `scripts/verify_gpu.py --help`，各专题的命令和阈值见上表。

八层 Loop 压力测试曾连续两次漏报数值进度。旧界面在拓扑校验期间切为不确定进度，较短的顶点和面处理阶段又可能落在两次 UI 刷新之间。修复后校验期间显示已经完成校验的层数，其他阶段仍显示实际处理数量。786432 面的 Release 回归已通过，测得事件排队最长 31ms。

同一几何回归在 ASan/UBSan 与 Vulkan 同步验证下通过，验证错误为 0。CPU-only CLI 的动态库列表没有 Qt、Vulkan 或 CUDA。参考包解压到含中文和空格的新目录后，CLI 重新加载出 4 个实例和 1 个介质区域。
