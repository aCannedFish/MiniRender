# SSS 界面

日期：2026-11-12。A7.6 加入物体页的 SSS 光学草稿、预置、PT 入口、Vulkan 表面近似和四个可编辑场景。操作与代码阅读顺序见 [SSS 界面](../SUBSURFACE_UI.md)。

## 完成范围

- 吸收 RGB、约化散射 RGB、密度和大理石/蜡预置，折射率沿用材质字段。
- 整组参数应用、恢复草稿、页内校验、撤销重做和未编辑分量的 double 精度。
- 新文档同步、无关编辑保留草稿、已有任务查看和启动快照保护。
- 纹理转换约束；选中 SSS 导入纹理时保留资源并说明使用条件。
- 按材质缓存的 PBR 表面近似，光学编辑复用网格和描述符。
- 四个快速导入模板，保留原有九个模板，合计十三个。

## 复验

```sh
cmake --preset macos-desktop-release
cmake --build --preset macos-desktop-release --parallel 4
ctest --preset macos-desktop-release --output-on-failure
python3 scripts/verify_gpu.py \
  build/macos-desktop-release/src/app/desktop/minirender_desktop.app \
  --scene scenes/studio.json --subsurface-check --timing-only \
  --output outputs/a7.6/ui --timeout 300
python3 scripts/verify_gpu.py \
  build/macos-desktop-release/src/app/desktop/minirender_desktop.app \
  --scene scenes/studio.json --presets-check --sync-validation \
  --output outputs/a7.6/presets --timeout 300
```

日志位于 `work/sss-ui-*.log`，图像和可编辑测试文件位于 `outputs/a7.6`。自动回归始终使用隐藏窗口。
