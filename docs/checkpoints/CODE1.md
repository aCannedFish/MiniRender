# 工程整理

日期：2026-11-16。统一代码排版，清理重复源码和冗余依赖，梳理工作台职责，并补充文件、核心接口和关键实现的说明。目录与算法入口位于 README.md，后续维护规则记录在 AGENTS.md。

## 排版与命名

`.clang-format` 统一 4 空格缩进、100 列换行、连续赋值及成员声明对齐、控制流花括号和函数间空行。函数声明保留独立排版，避免长返回类型把函数名推到过远位置。并列的基础变量声明拆成独立行。377 个自有 C++/GLSL 文件通过格式检查。

GLSL 的 include 顺序保留，由 `shaders/.clang-format` 单独约束。普通 C++ 继续排序 include。VS Code 自带的格式化器可以解析配置。

清理了本地四份未跟踪的数字后缀源码副本，删除前逐字节确认与正规文件一致，正规文件保留。`scripts/check_source_names.py` 检查自有源码目录中的 snake_case 文件名，覆盖未提交副本，并接入 macOS/Windows CI。

## 模块边界

工作台实现由以下文件组成：

| 文件 | 职责 |
| --- | --- |
| `workbench.cpp` | 窗口、工具栏、面板协调、编辑事务及交互入口 |
| `workbench_properties.cpp` | 物体、材质、灯光和相机的控件绑定与刷新 |
| `workbench_assets.cpp` | OBJ、纹理、环境图与场景导入，模板安装及同步保存 |
| `workbench_geometry.cpp` | 几何任务的固定输入、完成检查、资产替换和导出 |
| `workbench_widgets.cpp` | 数值显示、三分量输入和表单容器的实现 |
| `workbench_internal.hpp` | 内部声明及必须在头文件中定义的后台任务模板 |

非模板控件实现移入 `.cpp`，内部头文件只保留共用类型、声明和模板。各翻译单元明确包含自己使用的 Qt 类型。工作台主文件从 1911 行降至 944 行，接口名称与调用顺序保持一致。

算法公开接口位于 `include/minirender`，实现及内部辅助类型位于对应的 `src` 模块。README 给出每个算法的直接入口，相关实现文件开头指向接口。文件说明覆盖职责；核心参数和任务接口补充单位、所有权、线程、状态转换及结果含义。复杂实现按资源准备、计算、同步和发布步骤保留注释。

## 验证

- 123 个生产翻译单元通过 `clang-tidy` 的 `clang-analyzer-deadcode.DeadStores` 与 `misc-unused-parameters` 检查，没有诊断。分析使用与编译数据库一致的 SDK。
- Release 与 ASan/UBSan 核心测试各 298/298 通过。
- 24 组隐藏窗口回归通过，覆盖场景、纹理、线框、SSAO、IBL、交互、参数响应、操纵器、表面朝向、主题、原色、轮廓、几何、自适应、点云、SDF、布料、模拟、离线、SPPM、体积、SSS、光场及全部模板。
- ASan/UBSan 下的主题、几何任务和光场专项通过 Vulkan 同步验证，错误数为 0。
- 128×128、32 spp、深度 10、MIS、seed=101、4 线程的 Cornell Box PNG/EXR 与整理前逐字节一致。
- Debug 和 Release 编译数据库均包含分拆后的工作台源文件，README 的本地路径链接检查通过。

编译中发现的测试断言整数/浮点混合比较，改为明确的浮点常量。修正后增量构建没有这类警告。
