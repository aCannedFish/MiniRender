# 实时 IBL

日期：2026-11-04。完成 Qt/Vulkan IBL 接入及 A3 本机验收。

## 完成范围

- 漫反射、镜面粗糙度数组、BRDF 表和源图的浮点上传与显式过滤。
- Lambert 与 GGX 导体的环境照明、可独立关闭的环境背景。
- 最新来源任务、取消/重试、独立 BRDF 复用和两个环境缓存项。
- 环境图专用导入，场景强度/旋转/常量 RGB 编辑、撤销/重做和保存重开。
- 阶段/实际像素进度、过期任务过滤、活动任务退出。
- SSAO 与 IBL 漫反射合成，保持镜面与背景原值。

## 任务检查

Debug 和 Release 的同步验证均通过，Vulkan 错误为 0。检查覆盖部分准备时取消、等待取消后不自动重启、显式重试、连续来源变化、独立 BRDF、重开文件后新资产预处理，以及活动 worker 下退出窗口。

稳定窗口后的 heartbeat 最大间隔为 Debug 95ms、Release 52ms，阈值 500ms。该统计排除启动和显式截图/编码。真实桌面输入会改变测试相机和计时，自动回归现带有窗口标识并隔离原生键鼠/失焦事件；合成输入仍执行捕获恢复检查。普通启动不安装过滤器。

桌面 Debug/Release 的 CPU/CLI 回归均为 86/86。标准场景、SSAO、纹理、线框、交互和离线回归均通过。20 万三角形场景的 14 项参数回归最长回调约 0.98ms、下一帧最长 69ms，普通编辑未重建网格或材质描述符。

另外构建了带 ASan/UBSan 的桌面程序，完整运行 IBL 同步验证及活动任务退出，未报告内存/未定义行为或 Vulkan 错误，heartbeat 最大间隔为 87ms。第三方全局对象的 leak 检测关闭；插桩计算使用单独延长的自动测试预算。命令如下：

```sh
ASAN_OPTIONS=detect_leaks=0 MINIRENDER_IBL_TEST_TICKS=6000 python3 scripts/verify_gpu.py build/macos-desktop-sanitize/src/app/desktop/minirender_desktop.app --scene scenes/studio.json --ibl-check --sync-validation --output outputs/ibl-sanitize --timeout 700
```

普通启动界面也通过原生文件对话框导入了 512×256 EXR，观察到真实的 11008/49152 像素进度，再用键盘提交 90° 旋转。字段和底部说明无遮挡，截图已导出。此处未执行原生鼠标拖拽，拖拽恢复的证据来自程序内 Qt 事件回归。

## 复验

```sh
cmake --build --preset macos-desktop-debug
ctest --preset macos-desktop-debug
python3 scripts/verify_gpu.py build/macos-desktop-debug/src/app/desktop/minirender_desktop.app --scene scenes/studio.json --ibl-check --sync-validation --output outputs/ibl --timeout 180
```

`outputs/a3.2b/final-debug` 与 `final-release` 保存逐阶段 HDR/PNG、场景及日志。生成的 `saved.json` 可用普通桌面入口重新打开；自动回归结束时会故意切换新来源并退出，用于检查取消与资源收回。

GPU 证据来自 Apple M3/MoltenVK，Windows 桌面和 NVIDIA 运行时继续按 B 阶段验证。实现和源码顺序见[环境界面](../ENVIRONMENT_UI.md)，算法及原文来源见 [IBL](../IBL.md)。
