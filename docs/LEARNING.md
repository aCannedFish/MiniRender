# 阅读路线

先选一个能看到结果的场景，再沿一次操作找代码。所有示例都使用同一个场景文档；桌面编辑器、CPU 核心与 Vulkan 显示可分别调试。

## 场景与像素

在“快速导入”中打开 Cornell Box，移动短方块，运行离线路径追踪。先读[场景与资产](SCENE.md)和[射线求交](INTERSECTION.md)：编辑器保留对象与网格资产的关联，渲染任务启动时固定相机、材质和网格引用，BVH 找到射线最近的表面。随后读[路径追踪](PATH_TRACING.md)和[采样](SAMPLING.md)，跟踪一次 BSDF 采样、直接光采样及两者的 PDF 如何进入 MIS 权重。换成小光源模板，在相同 spp 下分别导出三种采样模式的 EXR。

切回实时预览，打开[SSAO](SSAO.md)的原始与滤波视图。它从屏幕深度重建位置，再沿法线半球检查遮挡。切换直接光、金属反射和环境漫反射，观察只有环境漫反射项使用 AO。实时与离线的图像都在线性空间计算，屏幕显示步骤见[HDR](HDR.md)。

## 网格与运动

从点云页对选中物体采样，计算法线并重建网格。读[点云重建](POINT_CLOUD.md)，在结果中找到边界环和未使用点数。然后在几何页对同一份网格分别尝试[Loop 细分](GEOMETRY.md)、[位移](DISPLACEMENT.md)、[简化](SIMPLIFICATION.md)与[重网格](REMESHING.md)。每次记录面数和轮廓变化，撤销回到共同输入再比较。重点看位置索引和面角 UV 如何分别保存。

在[布料模拟](CLOTH_SIMULATION.md)中跟踪一个粒子从外力、弹簧力到碰撞修正的过程。暂停后冻结姿态，给相同几何设置不同[布料材质](CLOTH_MATERIAL.md)。旋转织物方向，对照经纬线高光和几何褶皱。

## 光的传播

| 入口 | 建议观察 | 代码与模型 |
| --- | --- | --- |
| 有界雾 | 增减散射系数，比较区域内物体与区域外背景 | [体积散射](VOLUME.md)：先求射线与介质的区间，再决定表面或介质事件 |
| SPPM · 玻璃焦散 | 固定光子预算，比较迭代数和地面的焦散 | [SPPM](SPPM.md)：相机路径记录可见点，光子合并后更新半径与通量 |
| SSS · 蜡侧面扩散 | 光从顶部进入，在侧面出射；改变密度观察范围 | [次表面散射](SUBSURFACE.md)：读同一物体上两个不同表面点的贡献 |
| 光场 · 近远棋盘 | 采集一次，轮流聚焦 2m 和 6m，观察原始路径数 | [光场核心](LIGHT_FIELD.md)与[光场界面](LIGHT_FIELD_UI.md)：从已存子视图重建 |
| 距离场页 | 打开步骤数与法线视图，比较球面和 CSG 交界处 | [距离场](SDF.md)：沿射线步进，和解析球的命中距离比较 |

## 读测试

每个算法笔记都链接到实现和原始文献。在[本机验收](checkpoints/A9.md)找到对应的检查点，再读一个解析或几何对照用例、一个端到端检查。开始改代码前保存一张基线图，固定种子和输入。比较辐射值用线性 EXR；比较交互显示时再看曝光和 PNG。
