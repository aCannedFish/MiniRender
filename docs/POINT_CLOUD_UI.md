# 点云工具

右侧“点云”页支持 PLY 导入、表面采样、法线准备、多半径重建与 PLY 导出。点云预览使用独立视角，生成网格通过普通场景资产参与实时与离线渲染。

## 使用方法

1. 点击“导入 PLY 点云”，或在场景中选择物体后点击“从选中网格采样”。采样点数和种子在启动时固定。
2. 检查点云预览。可拖拽、平移和缩放视角；“定位点云”恢复完整视图。取消勾选“点云预览”返回场景。
3. 设置法线选项。关闭“估计法线”时使用导入文件或表面采样提供的原始方向。“准备法线与间距”可先显示统计，重建也会自动执行这一步。
4. 勾选“法线颜色”或“显示抽样法线”检查方向。需要反向时启用“整体翻转法线”，再准备或重建。
5. 使用按点间距建议的半径，或关闭建议后输入递增半径列表，点击“重建并应用到场景”。
6. 查看场景中的生成网格、边界与逐轮统计。结果可撤销/重做，继续移动、旋转、编辑材质，或进行其他几何操作。

面数、候选检查与邻域都有工作预算。阶段名称、实际处理数量和取消按钮位于点云页，状态栏也显示当前任务。参数编辑会保留给下一次任务，重建由按钮明确启动。

## 输出规则

从场景物体采样时，重建替换来源物体的网格，保留其当前变换和材质。共享原网格的其他物体保留原资产。后续调整参数会继续更新这个目标。

从文件导入时，首次重建创建新物体与独立材质。默认通过物体变换将结果缩放至约两米并放在地面上方，网格局部位置保留输入单位。关闭“文件导入结果适应场景尺寸”可保留原始尺寸。该选项在新建物体时生效。

同一份文件点云再次重建，会更新最近生成的物体，并保留手动移动、旋转和材质编辑。撤销创建后再次生成可以新建物体；重做也能恢复原结果。目标被其他几何操作替换后，页面提示重新采样。

结果包含实际使用点、未使用点、额外面扇顶点、面分量、边界环、边界边、Euler 数和候选检查数，每个半径分别列出新增面与边界变化。算法与统计含义见 [点云重建](POINT_CLOUD.md)。

## 预览参数

| 参数 | 作用 |
| --- | --- |
| 点大小 | 物理像素中的圆片直径，范围 1–32px |
| 法线颜色 | 按局部法线方向显示 RGB，采用与主场景法线视图相同的颜色约定 |
| 显示抽样法线 | 均匀抽取最多 10000 个方向，报告实际显示数量 |
| 法线长度 | 相对模型最长轴的百分比 |
| 显示重建边界 | 绘制已生成网格的全部边界段 |

点、法线与边界使用深度测试。预览坐标在后台居中并缩放，原始点云和网格位置保持原值。修改点大小、颜色、法线长度或显示开关仅更新显示参数，GPU 缓冲随数据版本更新。

预览中的相机导航独立保存，返回场景后恢复场景相机。主场景的材质、灯光和相机参数仍可编辑。点云预览可截图；EXR 导出在场景或离线结果视图中使用。

## 后台处理

`GeometryController` 统一管理点云、几何及文件任务，每次执行使用新的取消标记。PLY 解析、表面采样、邻域索引、法线、BPA、拓扑验证、实时网格展开与点云缓冲准备均在 worker 中完成。

法线缓存记录原始点云所有权及完整参数。匹配时重建直接复用，参数变化后重新准备。工作线程每约 25ms 更新可见进度，避免大量候选检查争用界面状态锁。

任务完成时核对场景代次、点云版本和目标网格。期间的材质与变换编辑会保留；目标被删除或网格引用变化时，旧结果显示为未应用。切换场景会取消旧任务并清理工具输入。每次成功应用形成一次场景历史事务。

已有离线任务继续使用原快照。单独查看和准备点云不改变场景；应用新网格后，旧离线图标记为过期，新任务使用最新几何。

## 文件

“导出当前点云 PLY”写出当前已准备的方向；未准备时导出原始输入。导出在后台执行，保护输入 PLY 和场景引用的原始资产路径。

工具输入通过 PLY 独立保存，场景 JSON 保存生成的网格及物体参数。重新打开场景后可以直接渲染和编辑网格，再从物体采样开展下一轮处理。生成网格的 OBJ 导出沿用“几何”页，场景保存沿用工具栏。

## 代码位置

- `render/point_preview`：居中缩放、交错属性、抽样法线和边界准备。
- `point_preview_renderer`：圆片、法线和边界管线及缓冲生命周期。
- `point_cloud_panel`：参数、工具输入、法线缓存、目标引用与统计。
- `point_cloud_tasks`：后台算法调用、进度限频、缓冲准备和文件保护。
- `point_cloud_workbench`：文件入口、来源核对、新物体/替换事务及预览切换。
- `point_cloud_smoke`、`point_cloud_editor_smoke`：独立 GPU 对照与实际界面回归。

## 复验

```sh
cmake --preset macos-desktop-release
cmake --build --preset macos-desktop-release
python3 scripts/verify_gpu.py \
  build/macos-desktop-release/src/app/desktop/minirender_desktop.app \
  --scene scenes/studio.json --points-check --sync-validation \
  --output outputs/a5.2/full --timeout 500
python3 scripts/verify_gpu.py \
  build/macos-desktop-release/src/app/desktop/minirender_desktop.app \
  --scene scenes/studio.json --points-check --timing-only \
  --output outputs/a5.2/timing --timeout 500
```

测试使用隐藏窗口和离屏 Vulkan。普通响应计时与同步验证分别运行，显式图像读回和参考计算暂停响应计时。
