# 距离场界面

右侧“距离场”页提供独立的 SDF 文档、实时视图和编辑历史。图元和算法见 [距离场](SDF.md)，测试结果见 [A5.3b 验收](checkpoints/A5.3b.md)。

## 使用

1. 点击“示例”，载入球减盒、旋转圆环和地面，打开距离场视图。
2. 在“编辑节点”中选择图元，修改半径或半长、位置、旋转、均匀缩放和颜色。
3. 在“视图”中切换表面光照、法线、深度或步数热图，使用阴影开关比较遮挡。
4. 左拖环绕、右拖转向、中拖平移，滚轮和 WASDQE 沿用场景相机操作。
5. 使用本页“保存”保存距离场和当前视角。“打开”会替换本页文档，并允许撤销。

新增图元先作为独立节点保留。将它设为根节点可以单独查看；使用“根与所选”一行的并集、交集或差集，可以将当前根作为 A、选中节点作为 B，创建新的根。差集表示 A 减 B，切面使用 B 的颜色。

选中已有组合节点后，可修改左右子节点引用。循环引用和非法尺寸会显示错误，控件恢复到已提交的值。修改某个坐标分量时，其余分量保持文件中的精度。

“删除未引用节点”用于清理未参与其他节点引用的节点。先更换根或子节点引用，再删除原节点。本页撤销/重做最多保留 64 次编辑，独立于顶部主场景历史。

关闭“显示距离场”可返回主场景。点云、离线结果和距离场视图互相切换时保留各自的相机，主场景资产保持原值。

## 文件

本页保存 `minirender-sdf` 文档，建议扩展名为 `.sdf.json`。顶部工具栏的保存仍用于三角网格场景。距离场文件包含图元、CSG 引用、光照、步进参数和当前视角，可在其他设备重开。

打开采用先解析、验证，再替换文档的顺序。无效文件保留当前编辑。保存已有文件时检查其格式，避免将主场景 JSON 覆盖为距离场文件。

截图保存当前显示图像。顶部“导出 EXR”保存当前距离场视图的浮点结果：表面模式保存曝光和色调映射之前的光照；法线、深度和步数模式保存对应的诊断值。

## GPU 管线

`SdfRenderer` 使用 `ScreenPass` 执行两个全屏三角形。片元着色器从像素中心生成针孔射线，按后序求值图元和 CSG，执行 sphere tracing 与方向光阴影，将结果写入线性 `RGBA32F` 图像。

独立显示 pass 对表面模式执行曝光与 Reinhard 色调映射，诊断模式保留数值，再由 sRGB 附件编码。读回使用原始浮点图像，曝光不会改变 EXR 中的值。最近邻采样器满足浮点纹理的基础设备要求。

节点记录为 112 字节，帧参数与 64 个节点合计 7360 字节。C++ 用 `static_assert` 检查大小和偏移，与 GLSL 的 `std140` 一致。图元使用基础 Vulkan 图形管线，不依赖 NVIDIA 扩展。

CPU 在 double 中将逆变换和包围盒移到相机原点，再转为 float 上传，减少大坐标相减的误差。图发生改变时重新编译最多 64 个节点；相机和显示参数改变只更新帧 UBO，三角网格不重新上传。

所有写入和资源替换发生在上一帧 fence 完成之后。读回先将图像转为 transfer 布局，复制到可读缓冲，再恢复 shader-read 布局。交换链缩放和退出分别释放显示管线、目标图像和设备资源。

## 步进参数

- 最大步数控制主射线预算，阴影步数单独控制光照查询。
- 绝对容差按米设置，相对容差随射线距离增加。
- 法线差分指定中心差分的世界空间间距。
- 最远距离限制追踪区间，安全系数决定每次前进距离的比例。

品红像素表示射线耗尽预算。步数热图用于观察轮廓和掠射区域的收敛情况。默认示例为主射线保留 512 步；测试中的交集场景使用 1024 步覆盖掠射样本。

## 阅读顺序

1. `sdf_panel.hpp/.cpp`：控件、候选文档验证、独立历史及文件入口。
2. `vulkan_viewport.*`：独立相机、模式切换、帧同步及 HDR 读回分发。
3. `sdf_renderer.hpp/.cpp`：UBO 打包、追踪 pass、显示 pass、读回与释放。
4. `shaders/sdf.vert`、`sdf.frag`：两个三角形、距离求值、步进、法线和阴影。
5. `shaders/sdf_display.frag`：表面与诊断模式的显示变换。
6. `sdf_smoke.cpp`、`sdf_editor_smoke.cpp`：解析及 CPU/GPU 对照、控件和文件流程。

## 复验

```sh
cmake --preset macos-desktop-release
cmake --build --preset macos-desktop-release --parallel 3
python3 -B scripts/verify_gpu.py \
  build/macos-desktop-release/src/app/desktop/minirender_desktop.app \
  --scene scenes/studio.json --sdf-check --sync-validation \
  --output outputs/a5.3/validation --timeout 240
```

响应测量使用 `--timing-only`，单独执行并去掉 `--sync-validation`。所有自动回归默认使用隐藏窗口和离屏 Vulkan 图像，不置顶或激活窗口。Windows 使用同一实现，原生驱动与桌面验证按 B 阶段安排。
