# 原色预览

原色预览用于检查模型、纹理、摆放和遮挡关系。启动应用或快速导入内置场景时默认选择该模式。在视口上方的下拉框切换，也可以在“场景与渲染 → 相机 → 显示”中选择。

## 显示规则

模式使用均匀的白色环境，直接显示线性底色与底色纹理的乘积。金属使用自己的底色；布料还乘上经纬纱线的覆盖率加权颜色。自发光面保留发光颜色，将峰值超过 1 的亮度归一化，便于辨认灯具。

深度测试与单面、双面设置照常参与遮挡。默认接触遮蔽在墙角、模型底部和相邻表面产生轻微暗化。关闭“场景与渲染 → 实时 → 原色预览接触遮蔽”后，可以查看未暗化的原色。

方向光、场景环境、阴影、反射和曝光不参与原色计算。显示时对颜色做 sRGB 编码，保留白色和纹理颜色。FXAA 可以平滑轮廓。

## 使用方式

- 检查初始模型或导入 Cornell Box：选择“原色预览”。
- 调整实时方向光和环境反射：选择“光照合成”。
- 比较实际面积光、间接照明、玻璃、体积和 SSS：在“离线”页运行渲染。
- 原色模式下的 EXR 导出保存当前线性预览颜色；光照模式保存对应的线性光照结果。

预览模式和接触遮蔽属于视口设置。场景文件中的光源、材质和环境参数保持各自的实际值，离线任务继续读取普通场景快照。

## 实现位置

1. `scene.frag` 在完成纹理采样和法线输出后计算原色，跳过后续光照。
2. `SceneRenderer` 用场景包围盒对角线的 4% 作为接触半径，偏移为半径的 2%。相机缩放不改变这个世界空间半径。
3. `SsaoPass` 使用独立的预览开关，执行 32 样本采样和双边滤波。合成时遮蔽系数最低为 0.65。
4. `post.frag` 对原色直接编码；光照模式继续使用曝光和 Reinhard。
5. `preview_smoke.cpp` 用 CPU BVH 对照可见材质，并检查纹理、灯光独立性、接触遮蔽、显示编码和切换后的离线结果。

既有法线、深度、线框与 AO 模式保留编号，原色模式追加为 6。预览切换复用网格和描述符；渲染帧跳过方向光阴影绘制。
