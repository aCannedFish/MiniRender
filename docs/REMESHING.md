# 重网格

各向同性重网格按目标边长调整三角形分布。右侧“几何”页选择“各向同性重网格”，设置边长和轮数后点击生成。输入为当前物体的局部网格，距离单位为局部米，物体变换保持原值。

## 算法

给定目标边长 $L$，每轮执行：

1. 分裂长度大于 $4L/3$ 的边，为两个相邻面创建同一个新位置。
2. 折叠长度小于 $4L/5$ 的边，检查合并后的边不会超过长边阈值。
3. 翻转非保护内边，降低四个端点的价数偏差平方和。内部顶点目标价数为 6，边界为 4。
4. 根据一环均值计算切向位移，并将候选位置投影回原表面。

分裂与折叠使用带版本的优先队列，分别优先处理最长和最短的边。局部修改后更新邻接及相关版本，旧候选直接丢弃；队列中的失效记录过多时重建。每轮结束清理已删除元素，维持工作集规模。

对位置 $p_i$、单位面积加权法线 $n_i$ 和邻点均值 $g_i$，切向更新为

$$
p_i'=p_i+\lambda(I-n_i n_i^T)(g_i-p_i).
$$

采用 Jacobi 更新，所有候选都依据本轮旧位置计算。若同时更新造成退化、翻面或 UV 方向翻转，减半步长并重新投影，最多试探八次。仍无法接受时保留本轮旧位置并报告拒绝数量。

## 原表面

原始输入在任务期间固定。沿保护边将面连接图分开，各组原三角面分别建立 `MeshSurface` 查询树。独立连通分量使用不同查询组，折痕和属性接缝两侧的点也从各自的原表面取样。

分裂、折叠以及平滑后的自由位置均查询原表面最近点；保护位置保持不变。新位置存回 float 后再检查几何合法性。投影返回的重心坐标同时用于插值原面角 UV，保持参数与几何位置对应。

界面默认启用投影。关闭后可单独观察切向平滑，UV 按邻点均值随更新插值。输出始终附带相对输入的双向表面距离。

## 约束

输入必须通过有向流形半边检查。分裂按面绕序建立子面，折叠使用 link 条件及重复面检查，翻边检查新对角线尚不存在。所有剩余面的面积和新旧法线投影必须为正。输出再次检查 Euler 数、边界环、连通分量和孤立位置数量。

默认固定边界、UV 接缝、硬法线与夹角大于 $60^\circ$ 的几何折痕。长保护边可以细分，两个子边继承保护标记。原保护顶点保持原位置，折叠跳过属性接缝顶点，翻边保留保护边。

面角属性独立于共享位置。分裂时分别插值两侧 UV 和法线，保留接缝；自由区域通过原表面查询传递 UV。硬法线顶点保留各面角方向，其余法线按面积重新计算。对有定义方向的 UV 三角形，还检查局部操作前后的 UV 面积符号。

## 参数

| 参数 | 含义 |
| --- | --- |
| 目标边长 | 默认 0.1 局部米，控制三角形尺度 |
| 迭代次数 | 0–20，默认 5；0 轮检查并返回原网格 |
| 面数上限 | 核心默认 200 万、最大 1600 万；界面默认 50 万、最大 100 万 |
| 平滑步长 | 0–1，默认 0.5 |
| 投影与 UV | 默认开启，使用启动时的原表面 |
| 保护选项 | 与 QEM 页共用边界、接缝、硬法线及折痕设置 |

界面依据数组规模估计输入工作集，限制为 2 GiB。实际增长由面数上限检查，分裂会在分配新面前检查预算；超限和取消均保留场景中的原资产。参数编辑只更新设置，点击生成后才运行。

## 质量指标

结果显示分裂、折叠、翻边、顶点更新和拒绝次数，以及实际完成的轮数。顶点更新包含位置或 UV 的变化，操作次数跨轮累加。

报告保留本次任务启动时的目标边长。计算期间可编辑下一次任务的参数，当前结果继续对应已固定的输入设置。

边长按唯一几何边统计最小值、平均值、中位数、P10、P90、最大值和目标区间 $[4L/5,4L/3]$ 内的数量。保护边也参与统计。角度报告最小内角，以及全部内角相对 $60^\circ$ 的平均绝对偏差：

$$
D_\theta=\frac{1}{3|F|}\sum_{f\in F}\sum_{k=0}^{2}|\theta_{f,k}-60^\circ|.
$$

表面距离使用两个方向的全部被引用顶点和面重心，查询另一网格三角形上的最近点，报告 RMS 与采样最大距离。细节见 [网格简化](SIMPLIFICATION.md) 的表面查询说明。

## 后台流程

`GeometryController` 固定输入与参数，在 worker 中执行重网格、校验及实时数据展开。`Workbench` 核对来源后，通过一次可撤销事务创建独立资产。共享原网格的其他实例及计算期间的材质、变换编辑保留。新资产可用于 Vulkan 预览、CPU 离线渲染、OBJ 导出和场景保存。

进度包括拓扑、原表面查询、边候选、分裂、折叠、翻边、平滑、投影、质量和误差阶段。数量属于当前阶段；边队列的总量包含新产生的候选。几何循环、排序和最近点查询定期检查取消，worker 不访问 Qt 控件或 Vulkan。

## 阅读顺序

1. `include/minirender/geometry/remesh.hpp`：设置、进度、质量与结果。
2. `src/geometry/remesh_mesh.*`：工作副本、邻接、保护边、三种局部修改与重编号。
3. `src/geometry/remesh.cpp`：固定参照表面、候选队列、平滑/投影和测量。
4. `tests/remesh_tests.cpp`：平面、硬边、曲面、接缝、独立分量及取消。
5. `examples/remesh.cpp`：质量报告、保存重开与固定种子 CPU 渲染。
6. `src/app/desktop/geometry_panel.cpp`、`geometry_controller.cpp`：界面与后台任务。

## 运行示例

```sh
cmake --build --preset macos-core-release
build/macos-core-release/minirender_tests '[remesh]'
build/macos-core-release/minirender_remesh_example
build/macos-core-release/minirender_remesh_example --stress
```

普通示例处理 studio 中无纹理的细分曲面，输出到 `outputs/a4.4`。原图、重网格图与保存重开的结果均采用 128×128、32 spp、seed=101，默认 MIS、最大深度 8 和 RR。压力模式使用 32768 面扰动平面，目标边长 $1/64$，运行 5 轮并报告实际质量。

- [PMP Remeshing](https://www.pmp-library.org/remeshing.html)，核对均匀重网格、原表面投影和特征保护。本实现采用一环均值平滑，并增加原三角面上的位置与 UV 查询。
