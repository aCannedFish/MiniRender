# 介质界面

右侧“介质”页编辑有界均匀 RGB 介质，参数随普通场景保存。体积效果由 CPU 离线渲染计算，实时视口用于编辑表面。算法和公式见 [体积散射](VOLUME.md)。

## 快速开始

1. 在工具栏“快速导入”或“介质”页选择“有界雾”“Cornell Box · 雾”或“透光孔光束”。导入会覆盖场景并设置推荐分辨率、样本数和深度。
2. 选择介质区域，调整坐标、RGB 吸收/散射系数或各向异性 $g$，点击“应用区域”。
3. 点击“开始离线渲染”。界面转到“离线”页，显示实际采样进度，可暂停、恢复、取消或导出。
4. 渲染期间继续编辑场景。应用新参数后，现有结果标为过期；当前任务继续使用启动时的快照。任务结束或取消后，重新开始使用新场景。

已有任务或图像导出正在执行时，介质页入口显示“查看渲染任务”，点击后查看同一任务。曝光和显示切换保持当前采样结果。

## 区域编辑

区域使用世界空间最小、最大坐标定义轴对齐盒。每个最小分量必须小于对应最大分量，启用区域的内部互不重叠。物体和区域分别保存坐标，移动物体后，区域保持原有位置。

“新增”创建一份独立区域。场景已有区域时，新区域放在它们右侧，避免初始重叠。最多保存 32 个区域。选择器中的名称可以修改，内部 ID 保持稳定。

“启用区域”决定该区域是否参与传输。关闭后仍保留参数，便于编辑和比较。启用时重新检查重叠条件。

| 参数 | 含义 |
| --- | --- |
| 吸收 / m⁻¹ | 光在对应 RGB 通道中被吸收的速率 |
| 散射 / m⁻¹ | 光在对应 RGB 通道中改变传播方向的速率 |
| 各向异性 g | 正值以前向散射为主，负值以后向散射为主，0 为各向同性 |

输入框省略小数尾零，悬停可查看场景中保存的完整 double 值。修改一个分量时，其余参数保留原始有效位。未编辑字段的精度通过保存和重开检查。

## 草稿历史

字段修改先进入草稿。“应用区域”验证整个候选区域集合，成功后形成一次场景历史。非法盒、重叠或其他校验错误显示在页内，当前场景保持原值。

有未应用改动时，“开始离线渲染”等待草稿应用。将改动全部恢复到原值后，会清除草稿状态。渲染中的“查看渲染任务”入口仍可使用。

新增、删除和参数应用分别支持一次撤销/重做。相机、材质等无关编辑保留未应用草稿；载入另一份场景或重新打开文件时，草稿更新为新文档的值。

“保存”和“另存”写入已应用参数。示例模板保留原值，首次保存选择用户路径。重开后可以继续编辑、渲染和比较。

## 示例

| 场景 | 可观察内容 | 建议编辑 |
| --- | --- | --- |
| 有界雾 | 有界介质对方块、阴影和背景的影响 | 系数、区域高度、方向光与相机 |
| Cornell Box · 雾 | 顶部面积光、墙面与介质之间的传输 | 光源大小、自发光、g 与区域密度 |
| 透光孔光束 | 真实顶板遮挡下的方向光束 | 移动/旋转顶板、方向光及介质系数 |

三个场景默认 320×320、128 spp、seed=101、最大深度 12，使用 MIS 和俄罗斯轮盘赌。完整列表见 [内置场景](BUILTIN_SCENES.md)。

## 实现

`VolumePanel` 持有文档参数副本与当前区域草稿。每个字段只修改对应分量，应用前调用共享的 `validate_medium_regions`。`Workbench` 将整组区域提交给 `SceneEditor`，更新场景快照并通知离线结果过期。

页面同步以介质数组和文档代数为依据。普通相机、灯光和材质编辑不会重置草稿；新文档即使带有相同参数，也重新同步。已应用区域为只读任务快照的一部分，后台线程读取自己的副本。

体积入口复用 `OfflinePanel` 和 `RenderSession`。页面根据现有任务/导出状态显示开始或查看入口。文件导入、任务采样及图像导出沿用后台流程，页面没有单独的渲染线程。

## 复验

```sh
cmake --preset macos-desktop-release
cmake --build --preset macos-desktop-release --parallel 4
python3 scripts/verify_gpu.py \
  build/macos-desktop-release/src/app/desktop/minirender_desktop.app \
  --scene scenes/studio.json --volume-check --timing-only \
  --output outputs/a7.2/release --timeout 240
```

移除 `--timing-only` 并加入 `--sync-validation` 可以检查 Vulkan 同步。自动回归始终使用隐藏窗口，参考计算和 GPU 读回在响应统计中单独排除。
