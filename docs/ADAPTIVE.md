# 自适应细分

自适应 Loop 将更多三角形分配给曲率大或高度变化快的区域。右侧“几何”页选择“自适应 Loop 与位移”，设置参照最大层级与目标误差，然后生成网格。结果使用普通网格资产，参与实时预览、阴影、CPU 路径追踪和文件保存。

## 参数

| 参数 | 含义 |
| --- | --- |
| 最小层级 | 所有原始面至少执行的 red 分裂层数，默认 0 |
| 参照最大层级 | 用来定义目标曲面的有限均匀 Loop 层级，界面默认 4，范围 0–8 |
| 局部位置误差 | 在物体局部空间比较位置，默认 0.005 米 |
| 固定视图投影误差 | 将参照点与近似点投影到任务启动时的视口，使用物理像素比较，切换时默认 1 像素 |
| 面数上限 | 包含最终过渡面的输出预算，界面默认 50 万、上限 100 万 |
| 高度位移 | 使用线性高度图 R 通道、幅度、中值和接缝容差，沿用均匀位移的控件 |

像素模式固定启动时的相机、物体变换及视口尺寸。任务期间可以移动相机，生成结果仍对应原视图。需要按新视角重新计算时，再次生成即可。局部米制误差随物体缩放一起进入世界空间。

报告显示本次实际参数、终端三角形的最大采样误差、各叶子层级面数、平衡分裂与过渡面数量，以及虚拟点和参照查询数量。达到最大层级后仍超出目标时，报告提示提高参照层级或放宽误差。面数或求值预算耗尽时任务失败，场景保留输入资产。

## 参照曲面

设最大层级为 $L$。几何参照采用原网格执行 $L$ 层均匀 Loop 后的分片三角形。所有输出角点在同一层级 $L$ 上取位置，因此粗细区域共用相同的边点。

`LoopHierarchy` 按需生成虚拟拓扑。原顶点的 ID 在各层保持一致，新顶点由“父层级、父边两个端点”唯一确定。误差查询仅展开命中的参数三角形及其支持邻域，无须先创建完整均匀细网格。

内部 even 顶点的权重沿用已有均匀实现：

$$
\beta_n=\frac1n\left[\frac58-\left(\frac38+\frac14\cos\frac{2\pi}{n}\right)^2\right].
$$

若顶点在出生层的位置为 $p$，其邻点为 $q_i$，出生后再更新 $t$ 次的位置可写成：

$$
p_t=p+(1-\rho^t)\gamma\sum_i(q_i-p),\qquad
\gamma=\frac1{n+3/(8\beta_n)},\quad
\rho=\frac58-n\beta_n.
$$

该式来自顶点与一环和的二维线性递推。边界仅取两个边界邻点，系数为 $\gamma=1/6$、$\rho=1/4$。odd 点在出生层按原有规则计算：内部边两端权重各为 $3/8$，两侧对顶点各为 $1/8$；边界取端点平均值。内部计算使用 double，输出位置使用 float。

一环保留有向顺序，以便求邻面和面积加权法线。even 点的新一环由其父层出边中点组成；odd 点的新一环由父边两侧的三角形推导。实现通过现有逐层均匀 Loop 独立核对位置、一环和法线，覆盖边界、异常价数和闭合网格。

位移参照在有限 Loop 三角形中插值基础位置与光滑法线，再读取连续双线性高度。输出角点使用同一套高度与方向。高度图的局部特征可以在达到 $L$ 后继续产生误差，因此最大层级不足会显示在报告中。高度采样及整条 UV 接缝检查由 `height_field` 与均匀位移共用，算法见 [高度位移](DISPLACEMENT.md)。

## 层级过渡

每个原三角形对应一棵四叉树。red 分裂将一个三角形替换为四个标准 Loop 子面。误差优先队列先处理偏差大的叶子，随后细化相邻粗叶，使共享边两侧的层级差最多为 1。

过渡面在提取输出时生成。邻面在共享边上有中点时，当前叶子使用对应模板：

| 有中点的边数 | 输出三角形数 |
| --- | --- |
| 0 | 1 |
| 1 | 2 |
| 2 | 3，选较短的内部对角线 |
| 3 | 4，使用标准子面 |

过渡面的顶点仍来自虚拟均匀层级。后续 Loop 参照查询沿用原有四叉树，避免过渡拓扑改变细分规则。提取后重新测量实际终端三角形；误差超标且允许继续细化时，将其所属 red 叶子放回队列。

共享位置 ID 保证中点唯一，面角 UV 按各自原始面插值。输出重新计算光滑法线，并用半边结构检查有向流形、Euler 数、边界环、面分量和孤立位置。报告中的层级取所属 red 叶子的层级，过渡面也计入该叶子。

## 误差采样

每个候选三角形检查边中点、四分点、重心和面内点，比较参照位置与角点线性插值。高度纹理检查还遍历 UV 覆盖范围内的 texel 中心。高度相对角点仿射插值有明显残差时，增加该处的参照查询，以捕捉局部凸起。

报告记录这些位置的最大采样误差。独立验收另外使用实际均匀 Loop 与位移网格，检查密集顶点、面重心和双向最近表面距离。纹理检查、支持点、一环缓存及输出面各有预算，工作循环定期检查取消标记。

像素误差使用固定的 `clip_from_object` 矩阵与视口像素尺寸。穿过相机平面的近似会继续细化；参照与近似位置相同时误差为零。矩阵和视口在核心 API 中使用 GLM 类型，核心库不依赖 Qt。

## 后台处理

`GeometryController` 在工作线程执行拓扑、接缝、采样、细化、平衡、过渡、法线与输出阶段，并准备实时顶点及索引数据。界面线程通过一次场景事务替换选中物体的网格，其他共享原资产的物体保持原有几何。

参数、输入网格、高度纹理及投影视图在启动时固定。任务期间的材质和相机编辑会保留。旧离线任务持有旧快照，结果标为过期；新的离线任务使用生成网格。撤销、重做及 OBJ/场景保存沿用 [几何工具](GEOMETRY_UI.md) 的流程。

## 阅读顺序

1. `include/minirender/geometry/adaptive.hpp`：参数、阶段与结果。
2. `src/geometry/loop_rules.hpp`：均匀与自适应共用的 Loop 权重。
3. `src/geometry/loop_hierarchy.*`：虚拟点、父边、一环和有限层位置递推。
4. `src/geometry/height_field.*`：连续高度采样与 UV 接缝检查。
5. `src/geometry/adaptive_surface.*`：根面参数、按需参照查询和高度特征采样。
6. `src/geometry/adaptive.cpp`：误差队列、邻接平衡、终端过渡和发布校验。
7. `examples/adaptive.cpp` 与 `tests/adaptive_tests.cpp`：实际均匀参照和独立误差检查。
8. `src/app/desktop/adaptive_smoke.*`：真实控件、CPU/GPU、历史、文件和取消回归。

## 运行示例

```sh
cmake --preset macos-core-release
cmake --build --preset macos-core-release
ctest --preset macos-core-release --output-on-failure
build/macos-core-release/minirender_adaptive_example
```

示例在 18 面平面上加入局部高斯高度特征，使用最大层级 6、目标误差 0.008 米。自适应结果为 756 面，实际均匀参照为 73728 面；求值虚拟点为 21246 个，均匀参照位置为 37249 个。双向表面采样 RMS 为 0.000818107 米，最大距离为 0.00789868 米。

结果写入 `outputs/a4.5`，包括可重开的场景、生成资产、PNG 与 EXR。`adaptive.png` 和 `uniform.png` 使用相同场景、相机与固定种子；保存重开后的最大 RGB 向量差为 $5.96046\times10^{-8}$。
