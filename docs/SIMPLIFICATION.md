# 网格简化

QEM 简化将当前网格转换为较低面数的独立资产，可用于模型 LOD、实时预览和 CPU 路径追踪。右侧“几何”页选择“QEM 网格简化”，设置目标面数后点击“生成网格”。参数编辑更新任务设置，生成过程在后台执行。

## 误差度量

对归一化平面 $p=(n_x,n_y,n_z,d)^T$，位置 $x=(x,y,z,1)^T$ 到平面的距离平方为

$$
(p^Tx)^2=x^T(pp^T)x.
$$

每个输入顶点累加相邻三角形的平面矩阵，得到 $Q_v=\sum pp^T$。折叠边 $(a,b)$ 后使用 $Q=Q_a+Q_b$，代价为 $x^TQx$。矩阵使用 10 个 double 保存对称上三角。平面归一化后代价单位为局部米的平方，不按面积加权。

候选位置包含两个端点、中点、线段上的最小值和三维驻点。三维驻点通过部分选主元的高斯消元求解；奇异系统继续使用其余候选。所有候选先转换为实际保存的 float 位置，再做合法性检查，取其中代价最低者。代价相同时优先选择短边，再按顶点编号排序，保证平面区域的选择稳定。

算法先减去输入包围盒中心，在这个坐标系中计算平面和二次型。输出时恢复局部坐标。这样可以减少模型远离原点时距离平方展开产生的消去误差。

## 合法折叠

输入须通过半边流形检查。工作网格保留稳定的面编号，顶点保存邻接面列表；折叠只改动两端点的一环。

1. 端点的共同邻居必须恰好等于边的对面顶点集合。
2. 两个边界顶点之间的内边保留，避免夹断边界。
3. 替换后的局部三角形按位置编号排序检查重复，包含四面体折叠后出现的反向重合面。
4. 至少保留一个相邻三角形，维持表面分量。
5. 剩余面的叉积平方大于 $10^{-20}$，新旧面积向量的点积为正。

输出再次建立半边拓扑，检查 Euler 数、边界环数和表面分量数与输入一致。几何检查针对局部退化与翻转，全局自交检测留在独立的几何检查范围。

## 属性保护

默认启用以下选项：

| 选项 | 处理方式 |
| --- | --- |
| 固定边界位置 | 边界顶点保持原位置；允许内部顶点并入它，两个固定顶点之间的边保留 |
| 保护 UV 接缝 | 同一共享位置的面角 UV 相差超过 $10^{-6}$ 时，保留该顶点的所有相邻边 |
| 保护硬法线 | 同一位置的归一化面角法线点积小于 $1-10^{-6}$ 时，保留该顶点的所有相邻边及原面角法线 |
| 固定几何折痕 | 相邻几何面法线夹角大于设置值时固定边端点，默认阈值为 $60^\circ$ |

固定位置与面角接缝分别记录。UV 连续区域按新位置在线段上的投影参数插值；未保护的法线按面积重新计算。被保护的面角 UV 和硬法线保持各自的值。关闭某项保护后，该类属性可随简化合并。

简化结果通过一次可撤销事务加入场景，仅替换启动任务时选中的物体。共享原资产的其他实例继续使用原网格。任务固定输入与设置，计算期间产生的材质、变换等编辑保留；目标删除、来源改变或场景切换时，过期结果不发布。

## 结果统计

面板显示请求面数、实际面数、折叠次数、受保护顶点数和停止原因。内部边折叠减少两面，边界边折叠减少一面。实际面数可以略低于请求值；约束或代价上限也会使其高于请求值。

`maximum_quadric_error` 限制单次候选的累计平面距离平方和，默认无限制。结果中的同名字段记录所有已接受折叠的最大代价。达到面数目标、没有合法候选、达到代价上限分别对应 `target_reached`、`constrained`、`error_limit`。

独立表面检查使用两个方向的全部被引用顶点及三角形重心。每个样本查询另一网格三角形上的最近点，分别报告 RMS、最大距离与样本数，再按样本数合并为双向 RMS。距离单位为局部米，最大值指采样集合中的最大距离。输入已满足目标或完全无法折叠时，结果沿用原指针，距离为零并省去采样。

`MeshSurface` 为局部三角形表面建立中位数 AABB 树。最近点先计算面内投影，再检查边线段；查询结果包含原面编号和重心坐标，可供后续表面投影插值属性。

## 后台执行

候选边存入最小堆，每个元素记录端点版本。邻域改变后递增相关版本，旧元素出堆时直接丢弃。受影响顶点的所有相邻边重新计算，确保之前被约束的边有机会再次参与。失效元素过多时重建堆，控制历史候选占用的内存。

输入校验、二次型、候选边、折叠、输出和表面误差分别报告进度。回调在调用线程执行，循环与阶段边界检查取消。Qt worker 完成几何、校验和实时顶点准备后，GUI 线程发布资产并上传缓冲。取消与异常均保留输入，不发布部分网格。

## 阅读顺序

1. `geometry/simplify.hpp`：设置、停止原因、进度和统计。
2. `geometry/simplify.cpp`：二次型、工作网格、合法性和局部更新。
3. `geometry/surface.hpp`、`surface.cpp`：最近点与双向距离。
4. `tests/simplify_tests.cpp`：解析距离、属性、边界、孔洞、分量和取消。
5. `examples/simplify.cpp`：独立 LOD、导出、保存重开与固定种子渲染。
6. `src/app/desktop/geometry_panel.cpp`、`geometry_controller.cpp`：Qt 参数和后台任务。

以上 `geometry/` 头文件位于 `include/minirender/`，实现位于 `src/`。

## 运行示例

```sh
cmake --build --preset macos-core-release
build/macos-core-release/minirender_tests '[simplify],[surface]'
build/macos-core-release/minirender_simplify_example
build/macos-core-release/minirender_simplify_example --stress
```

普通示例对同一份四层 Loop 输入分别请求 768、384 面，生成独立 LOD。每个结果保存 OBJ、场景 JSON、128×128、32 spp、seed=101 的 EXR/PNG，并对保存重开的渲染逐像素比较。输出位于 `outputs/a4.3`。压力模式使用 49152 面输入，请求 12288 面，只输出计数、误差与耗时。
