# 光场界面

从工具栏“快速导入”选择“光场 · 近远棋盘”。光场页会打开，选中的近红棋盘距相机 2m，远蓝棋盘距相机 6m。两者均可移动、旋转或更换材质。用默认 5×5 视图、参考焦距 4m、采集半径 0.2m 采集后，点击“近焦”和“远焦”比较两个棋盘。

## 采集

宽、高和每像素样本数用于每张子视图。阵列行列须为 3–15 的奇数，中心格点对应针孔。采集使用当前相机和场景快照，PT 的采样方式、最大深度和 RR 参数沿用离线页。线程数为 0 时自动选择。开始后可暂停、恢复或取消。

面板分别显示采集样本、已写入视图、当前阶段和内存估算。子视图完成后可在视口预览。场景在采集期间发生修改时，面板提示快照已过期，当前任务仍计算启动时的场景。PT 与光场采集互斥；已有光场文件可以在 PT 运行时查看。

## 重聚焦

完整采集和打开文件后，面板显示图像尺寸、阵列、参考焦距、采集半径、视场角和原始采集路径数。拖动焦距或孔径滑块可以连续重建。焦距滑块覆盖参考焦距的 1/4 到 4 倍，数值框可输入更广范围。快捷按钮分别选择参考焦距的 1/2、1 和 1.5 倍。

孔径为零时显示中心视图。切换到“子视图”后按行列选择相机位置，行列从 1 开始。重建和子视图解码均使用后台读者及有界缓存，调整参数时保留最近一次请求。曝光只改变显示及 PNG 导出，原始采集路径数保持不变。

## 文件

“保存光场”写出完整的 `.mrlf`，其中含线性 RGB32f、相机、瞳孔位置和采集参数。“打开光场”在后台读取文件并完成首次重建，然后替换当前数据。失败时保留原有数据和画面。保存与重建所用的缓存受内存预算约束。格式与预算计算见[光场核心](LIGHT_FIELD.md)。

EXR 保留当前完整线性图，PNG 使用点击导出时的曝光和显示变换。视口预览的最长边限制为 1024，导出使用完整分辨率。工具栏“导出 EXR”按当前查看的图像来源选择实时、PT 或光场输出。

## 显示切换

勾选“查看光场图像”显示最近的光场结果，取消勾选返回实时预览。离线页的显示选项用于取回 PT 或 SPPM 的结果。后台任务完成后只更新属于自己的前台图像，其他结果保存在对应面板中，用户可再次切换查看。

## 阅读顺序

- `lightfield_panel.*`：采集设置、光学控件、文件入口和进度。
- `lightfield_controller.*`：采集会话、单个后台图像任务、取消、请求合并和不可变结果发布。
- `VulkanViewport::set_offline_image`、`OfflinePanel::poll`：显示来源及浮点图上传。
- `Workbench::export_display_hdr`：工具栏导出当前来源的完整图像。
- `lightfield_smoke.cpp`：控件操作、独立文件参考、Vulkan 像素回读、任务竞争和关闭检查。

## 复验

```sh
cmake --preset macos-desktop-release
cmake --build --preset macos-desktop-release --parallel 4
python3 scripts/verify_gpu.py \
  build/macos-desktop-release/src/app/desktop/minirender_desktop.app \
  --scene scenes/studio.json --lightfield-check --timing-only \
  --output outputs/a8.2/ui --timeout 300
```
