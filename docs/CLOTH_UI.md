# 布料播放

右侧“布料”页提供两个可编辑示例、固定步播放、物理参数与冻结操作。模拟和网格准备在后台执行，视口接收完整帧。物理公式见 [布料模拟](CLOTH_SIMULATION.md)，表面模型见 [布料材质](CLOTH_MATERIAL.md)。

## 操作

1. 在“布料”页选择“落球”或“悬挂迎风”，点击“载入示例”。这会覆盖当前场景，可通过撤销恢复。
2. 点击“播放”“暂停”或“单步”。播放、单步和重置会切回实时场景。单步推进一个逻辑帧，默认对应 1/60 秒。页面显示模拟时间、实际子步、弹簧长度比、接触数和计算时间。
3. 调整参数后点击“应用物理参数”。重力、风、刚度和阻尼保留当前姿态与速度；修改网格尺寸、行列数或固定点会恢复新网格的静止状态。应用与重置分别形成一次历史。
4. 在场景树选中布料或碰撞体，用移动轴和旋转环编辑。开始拖动会暂停模拟，松开后可以继续播放。碰撞球的缩放需三轴等比；物体页提供碰撞开关和摩擦系数。
5. 保存场景会写入当前可见帧的位置、速度和完整配方，重开后可以继续模拟。点击“冻结为网格”会移除模拟组件，保留当前几何与材质，随后可以使用几何工具。冻结支持撤销和重做。
6. 启动离线渲染会先暂停布料，并固定启动时的可见状态。再次播放后，已有离线结果标为过期。

有多个布料物体时，“模拟物体”选择器决定播放和冻结的目标。复制布料会创建独立的网格资产标识，两个物体初始可以共享只读网格数据，后续帧各自更新。

参数输入先保存在界面草稿中。物理任务固定启动时的参数，应用成功后才替换场景组件。计算较慢时，进度条显示准备、子步推进和显示数据准备阶段；暂停会取消尚未发布的帧，画面保留最后一个完整状态。

## 坐标

`ClothDefinition` 定义规则网格、物理参数和外力。配方与已保存的 `ClothState` 使用物体局部坐标，重力、风及碰撞环境使用世界坐标。位置与速度均为 double。

运行时先通过物体变换将静止网格、当前状态和速度映射到世界空间，再根据世界面积计算质量和所需子步。两条网格边向量可以不正交，因此非均匀缩放与旋转后仍能建立对应的弹簧系统。每次恢复使用固定的实际子步数，取界面下限与稳定性估计的较大值。

完成一帧后，`prepare_cloth_frame` 将位置和速度映回局部坐标，固定点恢复为精确静止值。显示网格的位置由同一份状态转成 float，法线使用当前三角形的面积加权结果。组件构造时检查点数、固定点、拓扑、UV 和状态与网格的一致性。

编辑物体变换后，局部姿态和速度随物体变换，世界重力和风方向保持其环境含义。恢复模拟时重新计算世界质量、弹簧长度与实际子步。

场景中的 `ClothCollider` 保存局部球心或平面点、法线、半径、摩擦与启用状态。球心使用物体矩阵变换，球半径乘以均匀缩放；平面法线使用逆转置。渲染可见性与碰撞开关分别控制，隐藏的碰撞体也可参与模拟。

## 调度

`ClothController` 持有一个后台任务。运行中的任务独占 `ClothSimulation`，主线程持有场景组件与状态摘要。Qt 定时器请求下一逻辑帧，物理系统始终使用固定时间间隔。计算变慢时播放速度下降，子步长度保持固定。

每个任务记录物体 ID、文档代数、组件指针、物体变换和碰撞环境。提交前再次检查这些来源。切换场景、删除目标、撤销、变换或碰撞体编辑会取消旧任务。材质与相机编辑不改变物理来源，允许当前模拟继续。

暂停会增加任务代数，并请求取消。后台任务即使已接近完成，其结果也会因代数不符而丢弃。后续计算从文档最后显示的组件恢复，避免把未显示的子步带入新任务。连续应用参数时保留最后一份请求，在当前任务退出后执行。

进度通过独立的小结构传递，访问由互斥锁保护。后台代码不读取 Qt 控件。析构时先取消，再等待本控制器的任务退出，随后释放模拟器。

## 场景更新

`SceneEditor::update_cloth_frame` 检查预期组件和变换，验证新组件与网格后发布场景。播放帧更新不增加撤销历史，参数应用、重置和冻结各增加一次历史。已有历史与离线任务通过只读快照保留原帧。

新帧携带后台准备的 `RasterMeshData` 和网格验证缓存。主线程更新场景引用，GPU 上传顶点。三角面角展开后的线框索引只取决于面数，相同顶点数量可以复用原来的顶点与索引缓冲。

`SceneRenderer` 在上传前收集新场景使用的全部网格所有者。只有已被新场景释放、且容量匹配的旧 GPU 网格可以被移动复用。另一个可见物体仍使用旧网格时，动态帧创建自己的缓冲；后续帧继续复用这一份缓冲。上传统计分别记录顶点上传、缓冲分配、索引上传和复用次数。

## 文件

场景对象可包含两个可选字段：

| 字段 | 内容 |
| --- | --- |
| `cloth_simulation` | 网格配方、固定点、物理参数、附加环境、场景碰撞开关、逻辑帧、局部位置与速度 |
| `cloth_collider` | 球或平面的局部参数、摩擦与启用状态 |

普通 OBJ 继续保存显示网格。载入场景时，模拟状态必须与该资产的点数、拓扑、UV 和 float 位置一致。维数、索引、子步与帧数按整数读取，负数、分数和超出范围的值会被拒绝。冻结后保存的场景对象不再包含 `cloth_simulation`。

## 阅读顺序

| 文件 | 关注内容 |
| --- | --- |
| `include/minirender/simulation/cloth_component.hpp` | 配方、不可变组件与世界模拟接口 |
| `src/simulation/cloth_component.cpp` | 坐标转换、固定点与显示网格一致性 |
| `src/assets/cloth_simulation_io.cpp` | 配方和完整状态的 JSON 往返 |
| `src/scene/editor.cpp` | 帧发布、共享资产分离与历史 |
| `src/app/desktop/cloth_controller.cpp` | 单任务所有权、取消与结果验证 |
| `src/app/desktop/cloth_panel.cpp` | 草稿、实际子步、进度与操作按钮 |
| `src/app/desktop/cloth_workbench.cpp` | 示例、场景编辑、冻结与离线快照 |
| `src/app/desktop/scene_renderer.cpp` | 活跃所有者集合与动态缓冲复用 |

## 复验

```sh
cmake --preset macos-core-release
cmake --build --preset macos-core-release --parallel 3
build/macos-core-release/minirender_tests '[cloth-component]'

cmake --preset macos-desktop-release
cmake --build --preset macos-desktop-release --parallel 4
python3 scripts/verify_gpu.py \
  build/macos-desktop-release/src/app/desktop/minirender_desktop.app \
  --scene scenes/studio.json --simulation-check --timing-only \
  --output outputs/a6.3/timing --timeout 240
```

移除 `--timing-only` 并加入 `--sync-validation` 可以检查 Vulkan 同步。回归窗口保持隐藏，运行结束时还会检查后台任务与 GPU 资源的销毁结果。
